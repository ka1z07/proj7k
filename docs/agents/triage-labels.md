# 分流标签（Triage Labels）

技能（skills）基于五个标准分流角色运行。本文档将这些角色映射到本仓库 Issue Tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标准角色 | 我们仓库中的标签 | 含义说明 |
| ------------------------------ | ---------------- | ---------------------------------------- |
| `needs-triage`                 | `needs-triage`   | 维护者需要评估此 Issue                   |
| `needs-info`                   | `needs-info`     | 等待提交者提供更多信息                   |
| `ready-for-agent`              | `ready-for-agent`| 规范完整，已就绪可交由 AI Agent 自动实现 |
| `ready-for-human`              | `ready-for-human`| 需要人工介入实现                         |
| `wontfix`                      | `wontfix`        | 不予处理                                 |

当技能提及某个角色时（例如“应用 ready-for-agent 标签”），请使用表中对应的右侧标签字符串。

可直接修改右侧列以适配你实际使用的标签命名。
