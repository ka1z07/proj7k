# proj7k v0.3.0 发布说明

[English](https://github.com/ka1z07/proj7k/releases/tag/v0.3.0) · 简体中文 · [繁體中文](https://github.com/ka1z07/proj7k/blob/v0.3.0/docs/releases/v0.3.0.zh-TW.md)

v0.3.0 新增谱面编辑器、进步页和直播叠加层；不同工具的任务可以同时跑，运行中的任务也能取消；谱面生成全面改用 Mapperatorinator 模型；高速叠和偏重同几列的谱星级提高。

## 新内容

**星级有变化**（如果你把 proj7k 星级写进了 lazer，请重新同步）

- **高速谱更难**：速度不再是线性计算，同一个配置 BPM 越高难度涨得越快；高速同指小叠（minijack）单独计分；整张谱的星级不会远低于它最难的 8 秒。单键滚键基本不变。
- **偏重同几列的谱更难**：反复压在同几根手指上的谱以前被低估，现在同指成本加重。
- 全部星级与段位表重新标定。如果你用过「曲库同步」把 proj7k 星级写进 osu!lazer，请再跑一次。降阶器现在也会保持原谱的列分布，叠谱降阶后仍以叠为主。

**谱面编辑器**（侧栏「工具 → 谱面编辑器」）

- 以下落式 7K 轨道显示谱面并播放音乐，整首歌的时间轴，可按小节选择。
- 用模型重写任意小节：候选都会留下，先试听试打再采用。可锁定段落、让某段重复（或镜像）另一段，撤销 / 重做。
- 手动修改：在吸附网格上放置、移动、删除米键和长条，框选、镜像、平移、复制；改动时星级与不可打的音符实时更新。手改过的小节，之后的模型重写不会动。
- 可打开任意 osu!mania 7K 谱，拆分 / 合并 / 拖动段落，把两版并排对比并标出差异，也能读回你在 osu!lazer 自带编辑器里改过的版本。
- 「导入 osu!」把当前这一版作为新谱导入 lazer（不覆盖任何谱）；「打开文件夹」打开项目文件夹。

**谱面生成**

- **全面改用 Mapperatorinator 落键**：去掉了 proj7k 自己的落键模型（以及 Demucs 分轨）；第一次生成时下载模型（数 GB，强烈建议有 NVIDIA 显卡）。
- **修好长条**：以前重叠的长条和长条和弦会被合并成一根，长条谱因此简单得多（比如本应 7.5★ 只有 2.6★）。现在长条歌大约在 7–8★。
- **技法配比**：给关心的技法池拉一个星级范围，生成时留下最贴近这些范围的一张，降阶器再把每个池修到各自的范围里。
- **更快、更连贯**：不写 SV，有参考谱时借用它的 timing，可选快速模式（约快一倍，衔接处偶有空白），歌里重复的段落会复用同一个乐句，空白段会补写，重叠音符会清理。生成的谱全程同一流速。
- **段落**：每次生成存成项目，按 8 小节分段，可单独重写、锁定和锚定。
- **长条 LoRA（实验，默认关闭）**：针对长条歌微调的模型，长条谱更难，但混合歌会多写长条。
- 文件名含中文等非 ASCII 字符的音频现在能正常解码。

**降阶器**

- **按技法范围降阶**：给每个池一个星级范围，降阶器把超出上限的池降下来、守住到了下限的池，同时达到总目标。
- 批量提交：一次生成整条阶梯（目标段位及以下 N 档）。

**面板与任务**

- **任务并行**：不同工具（降阶、生成、lazer、profiler）的任务可以同时跑，绝不会有两个任务同时写同一个数据库。降阶和生成页各有自己的队列，可以连续提交。
- **取消运行中的任务**：运行中的任务会在下一个安全点停下（绝不会在写 lazer 曲库或数据库的半途中断），模型进程立即停止。
- **设置页**：语言、动画开关、悬停提示、任务结束提醒（角落提示、提示音、系统通知）、默认输出文件夹、默认打包 .osz / 加入 lazer 收藏夹、记住每个工具上次的选项。
- **进步页**（侧栏「进步」）：目标段位、总体与各技能的差距和按当前速度的预计，总体曲线与各技能小图。
- **打崩之后**，proj7k 会指出崩在哪里，并给出低一档的练习谱、回放诊断或直接看这一局（可在设置里关闭）。
- **直播叠加层**：给 OBS 或侧边窗口用的透明卡片，跟随你正在打的谱，显示星级、段位、各技能与你水平的对比和个人最好。在设置页生成并复制它的地址。
- 各处任务计时实时跳动，每个控件都有悬停提示，回放查看器新增音量滑块（每台电脑分别记住）。

在线谱面库 <https://7k.kaiz.dev/> 现在每页有自己的标题、摘要和 sitemap，方便搜索引擎收录。

## 安装或更新

**Windows 10 / 11**

1. 下载 [Release 页面](https://github.com/ka1z07/proj7k/releases/tag/v0.3.0) Assets 里的 **Source code (zip)**，解压到比如 `文档\proj7k`。更新时直接解压覆盖原来的文件夹。
2. 双击 **`install.cmd`**（如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」）。
3. 它会装好 Python 3.14、Node.js 和依赖，下载 proj7k 窗口，在开始菜单和桌面放快捷方式，然后直接打开。

**macOS**：解压后在终端运行 `sh install.sh`，以后双击 `proj7k.command` 打开。

需要 **osu!lazer**（不支持 stable）。完整教程见[中文使用说明](https://github.com/ka1z07/proj7k/blob/main/README.zh-CN.md)。

> `proj7k-windows.exe` 和 `proj7k-macos.zip` 是 proj7k 的窗口程序本身，安装脚本会自动下载，一般不用手动下。单独下载它是打不开功能的：功能在 proj7k 文件夹里，窗口只是它的外壳。

## 已知限制

- 星级与 v0.2.0 不同（见上）；如果你把 proj7k 星级写进了 lazer，请重新跑一次「曲库同步」。
- 谱面生成需要 Mapperatorinator 模型（数 GB），没有 NVIDIA 显卡会很慢。高难度长条歌生成的谱仍低于同曲人工谱，生成的谱面仍需要人看一眼再打。
- 程序没有代码签名，Windows 第一次运行 `install.cmd` 时会提示，Mac 上由安装脚本处理。
- 窗口程序不会自动更新：新版本出来后，下载新的 zip 覆盖原文件夹，再运行一次 `install.cmd` / `install.sh`。
- Linux 没有窗口程序，`proj7k.command` 会改用 Edge / Chrome 的应用窗口或浏览器打开。
- 任务只存在内存里：重启 proj7k 会清空任务列表。
