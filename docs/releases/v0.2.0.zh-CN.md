# proj7k v0.2.0 发布说明

[English](https://github.com/ka1z07/proj7k/releases/tag/v0.2.0) · 简体中文

v0.2.0 新增：主页的 osu! 登录、谱面生成的 AI 落键模型（实验）、密度更均匀的生成器（gen-6）、任务面板，并修好了「还原为官方星级」。

## 新内容

- **用 osu! 登录**：主页有「用 osu! 登录」按钮，登录后在 proj7k 水平旁边显示你的 7K 与 mania 总排名和 pp。登录走 osu! 官方页面，令牌只存在你自己电脑上（`~/.proj7k/osu_account.json`），不登录就不显示。
- **谱面生成：Mapperatorinator 后端（实验）**：在「谱面生成」里勾选「实验：Mapperatorinator 模型落键」，就改用 [Mapperatorinator](https://github.com/OliBomby/Mapperatorinator)（OliBomby，MIT）落键。它是在 ranked 谱上训练的 Whisper 类模型，节奏和键位一起写。proj7k 会跑几次，留下引擎星级最接近目标的一张。第一次勾选会下载安装它（PyTorch 与模型权重，数 GB）到 `~/.cache/proj7k/mapperatorinator`。强烈建议有 NVIDIA 显卡：RTX 5060 Ti 上每首约 4 分钟，CPU 或 Mac 会慢很多。命令行：`python3 -m proj7k.generator --backend mapperatorinator`。
- **谱面生成 gen-6：难度更均匀**：每 4 小节之间的密度拉平了，不会再出现长段几乎空白、旁边又是墙的情况。星级目标不变。
- **任务面板**：侧栏「工具」下新增「任务」页：所有降阶、生成、导入任务的状态、当前进度、耗时、错误和产物，点开看完整日志，排队中的任务可取消。侧栏会显示正在运行的任务数。
- **修复「还原为官方星级」**：曲库同步的还原现在能找到之前的备份，也不会被备份里的杂项中断，lazer 曲库能正常回到官方星级。
- **文档**：README 改为英文，另有简体与繁体中文使用说明；新增贡献指南、行为准则、安全政策与 issue / PR 模板。

在线谱面库 <https://7k.kaiz.dev/>（不用安装）现在也有英文和繁体中文界面。

## 安装或更新

**Windows 10 / 11**

1. 下载 [Release 页面](https://github.com/ka1z07/proj7k/releases/tag/v0.2.0) Assets 里的 **Source code (zip)**，解压到比如 `文档\proj7k`。更新时直接解压覆盖原来的文件夹。
2. 双击 **`install.cmd`**（如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」）。
3. 它会装好 Python 3.14、Node.js 和依赖，下载 proj7k 窗口，在开始菜单和桌面放快捷方式，然后直接打开。

**macOS**：解压后在终端运行 `sh install.sh`，以后双击 `proj7k.command` 打开。

需要 **osu!lazer**（不支持 stable）。完整教程见[中文使用说明](https://github.com/ka1z07/proj7k/blob/main/README.zh-CN.md)。

> `proj7k-windows.exe` 和 `proj7k-macos.zip` 是 proj7k 的窗口程序本身，安装脚本会自动下载，一般不用手动下。单独下载它是打不开功能的：功能在 proj7k 文件夹里，窗口只是它的外壳。

## 已知限制

- 程序没有代码签名，Windows 第一次运行 `install.cmd` 时会提示，Mac 上由安装脚本处理。
- 窗口程序不会自动更新：新版本出来后，下载新的 zip 覆盖原文件夹，再运行一次 `install.cmd` / `install.sh`。
- Linux 没有窗口程序，`proj7k.command` 会改用 Edge / Chrome 的应用窗口或浏览器打开。
- 生成和降阶的谱面仍需要人看一眼再打。Mapperatorinator 在长条多的歌上星级常常偏低。Demucs 分轨是实验功能，第一次勾选会下载数 GB。
- 任务只存在内存里：重启 proj7k 会清空任务列表，正在运行的任务暂时不能停止。
