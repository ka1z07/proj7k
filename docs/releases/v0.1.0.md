proj7k 的第一个正式版本：一个给 osu!mania 7K 玩家的桌面工具，读你本机 osu!lazer 的成绩和回放，告诉你现在什么水平、该练什么，再帮你出练习谱。

## 安装

**Windows 10 / 11**

1. 下载下面 Assets 里的 **Source code (zip)**，解压到比如 `文档\proj7k`。
2. 双击 **`install.cmd`**（如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」）。
3. 它会装好 Python 3.14、Node.js 和依赖，下载 proj7k 窗口，在开始菜单和桌面放快捷方式，然后直接打开。

**macOS**：解压后在终端运行 `sh install.sh`，以后双击 `proj7k.command` 打开。

需要 **osu!lazer**（不支持 stable）。完整教程见[中文使用说明](https://github.com/ka1z07/proj7k/blob/main/README.zh-CN.md)。

> `proj7k-windows.exe` 和 `proj7k-macos.zip` 是 proj7k 的窗口程序本身，安装脚本会自动下载，一般不用手动下。单独下载它是打不开功能的：功能在 proj7k 文件夹里，窗口只是它的外壳。

## 有什么

- **玩家主页**：现在的水平（段位与星级）、近 30 天变化、「下一步练什么」、星级进步曲线、八项技法实力、各段位通关情况。
- **游玩记录 / 曲库**：lazer 里的每一局和每一张 7K 谱，按 proj7k 星级、段位、技法筛选；点开一局能诊断、重看、切练习包。
- **实时雷达**：游戏里选歌时实时显示星级、段位、八项技法和难度时间线，附 OBS 叠加层。
- **回放与画像**：导入全部 lazer 回放，得出八项技法水平和发力习惯；回放查看器；在崩盘点切三阶练习包。
- **降阶练习**：把打不过的图降到目标段位或星级，保留主技法，一键导入游戏。
- **谱面生成**：给一首歌按目标难度生成 7K 谱（米键，可选长条与反键），按段落分配密度和写法。
- **曲库同步**：把 lazer 里的星级换成 proj7k 星级并打上段位、技法标签，随时可还原。
- **界面**：仿 osu!lazer 的深色界面和动画，无边框窗口，中文 / English。

在线谱面库不用安装：<https://7k.kaiz.dev/>

## 已知限制

- 程序没有代码签名，Windows 第一次运行 `install.cmd` 时会提示，Mac 上由安装脚本处理。
- 窗口程序不会自动更新：新版本出来后，下载新的 zip 覆盖原文件夹，再运行一次 `install.cmd` / `install.sh`。
- Linux 没有窗口程序，`proj7k.command` 会改用 Edge / Chrome 的应用窗口或浏览器打开。
- 谱面生成和降阶练习的结果仍需要人看一眼再打；Demucs 分轨是实验功能，第一次勾选会下载数 GB。
