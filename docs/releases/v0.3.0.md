proj7k v0.3.0 adds a chart editor, a progress page and a stream overlay, lets jobs run side by side and be cancelled while running, moves the chart generator fully onto the Mapperatorinator model, and rates fast jacks and column-heavy charts higher.

## What's new

**Star ratings change** (please re-sync if you write proj7k stars into lazer)

- **Fast patterns rate higher.** Speed now counts more than linearly: the same pattern at a higher BPM gets harder faster than before, fast same-finger minijacks are counted on their own, and a chart is never rated much below its hardest 8 seconds. Single-note rolls stay about the same.
- **Column-heavy charts rate higher.** Charts that keep hitting the same fingers were underrated; the same-finger cost is now weighted more.
- All star ratings and the dan table were recalibrated. If you used *Library sync* to write proj7k stars into osu!lazer, run it again so the library matches. The downscaler now also keeps the original chart's column balance and keeps jack charts jack-heavy while thinning them.

**Chart editor** (sidebar *Tools → Chart editor*)

- The chart drawn as a falling 7K playfield with the song, a whole-song timeline and measure selection.
- Rewrite any measures with the model: candidates are kept for you to preview and play before you adopt one. Lock sections, anchor one section to repeat (or mirror) another, undo/redo.
- Edit by hand: place, move and delete notes and long notes on a snap grid, box select, mirror, shift, copy; stars and unplayable notes update as you edit. Measures you edited by hand are left alone by later rewrites.
- Open any osu!mania 7K chart, split / merge / drag sections, compare two takes side by side with the differences coloured, and read back a version you edited in osu!lazer's own editor.
- *Import to osu!* sends the current take to lazer as a new chart (overwrites nothing); *Open folder* opens the project folder.

**Chart generator**

- **Mapperatorinator is now the only note writer.** proj7k's own note models (and Demucs stem separation) were removed; the model is downloaded the first time you generate (several GB, NVIDIA GPU strongly recommended).
- **Long notes fixed:** overlapping long notes and long-note chords were being merged into one, which made LN charts far too easy (for example 2.6★ instead of 7.5★). LN songs now come out around 7–8★.
- **Technique mix:** drag a star range for each technique pool you care about; the generator keeps the run closest to those ranges and the downscaler trims each pool into its own range.
- **Faster and more coherent:** no SV, timing borrowed from a reference chart when available, an optional fast mode (about twice as fast, slight gaps at seams), repeated parts of the song reuse the same phrase, empty stretches are refilled, and overlapping notes are cleaned up. Generated charts scroll at one constant speed.
- **Sections:** a generation is saved as a project split into 8-bar sections you can rewrite, lock and anchor.
- **Long-note LoRA (experimental, off by default):** a fine-tuned model for long-note songs; harder LN charts, but mixed songs get more long notes.
- Audio files with non-ASCII names now decode.

**Downscaler**

- **Per-technique ranges:** give each pool a star range and the downscaler brings pools above their ceiling down and holds those at their floor while hitting the overall target.
- Batch forms: a whole ladder (target tier plus N below) in one go.

**Dashboard and jobs**

- **Jobs run in parallel** when they use different tools (downscaler, generator, lazer, profiler), never two writing the same database. Downscaler and generator pages each keep their own queue; you can submit several in a row.
- **Cancel running jobs:** a running job stops at its next safe point (never in the middle of writing your lazer library or database); the model process is stopped at once.
- **Settings page:** language, animations, hover tips, job-end alerts (note, chime, system notification), default output folders, default .osz / lazer collection options, remember each tool's last choices.
- **Progress page** (sidebar *Progress*): target dan, overall and per-skill gap with a pace estimate, overall curve and per-skill charts.
- **After a failed play** proj7k shows where it broke and offers a practice chart a tier lower, a replay diagnosis, or the play itself (can be turned off in Settings).
- **Stream overlay:** a see-through card for OBS or a side window that follows the chart you are playing, with stars, dan, skills against your level and your personal best. Build and copy its address on the Settings page.
- Live job clocks everywhere, hover tips on every control, and a volume slider in the replay viewer (remembered per computer).

The online chart catalog at <https://7k.kaiz.dev/> now has its own page titles, summaries and a sitemap for search engines.

## Install or update

**Windows 10 / 11**

1. Download **Source code (zip)** under Assets below and unzip it (for example to `Documents\proj7k`). To update, unzip over your existing folder.
2. Double-click **`install.cmd`**. If Windows says "Windows protected your PC", click *More info* → *Run anyway*.
3. It installs Python 3.14, Node.js and the dependencies, downloads the proj7k window, adds Start menu and desktop shortcuts, and opens it.

**macOS:** unzip, run `sh install.sh` in Terminal, then open `proj7k.command` from then on.

Requires **osu!lazer** (stable is not supported). The UI is in Chinese by default; switch to English with the toggle at the bottom left or on the Settings page. Full guide: [README](https://github.com/ka1z07/proj7k#readme).

> `proj7k-windows.exe` and `proj7k-macos.zip` are the window itself; the install script downloads them for you. On their own they don't work: the features live in the proj7k folder, and the window is only its shell.

## Known limitations

- Star ratings differ from v0.2.0 (see above); re-run *Library sync* if you write proj7k stars into lazer.
- The chart generator needs the Mapperatorinator model (several GB) and is slow without an NVIDIA GPU. Its LN charts still come out below human charts of the same song at the top end, and generated charts deserve a look before you play them.
- The programs are not code-signed: Windows warns the first time you run `install.cmd`; on Mac the install script handles it.
- The window does not update itself: for a new version, download the new zip, unzip over the folder and run `install.cmd` / `install.sh` again.
- Linux has no window build; `proj7k.command` opens the app in an Edge / Chrome app window or your browser instead.
- Jobs live in memory: restarting proj7k clears the jobs list.
