# proj7k v0.2.0 釋出說明

[English](https://github.com/ka1z07/proj7k/releases/tag/v0.2.0) · [简体中文](https://github.com/ka1z07/proj7k/blob/v0.2.0/docs/releases/v0.2.0.zh-CN.md) · 繁體中文

v0.2.0 新增：首頁的 osu! 登入、譜面生成的 AI 落鍵模型（實驗）、密度更均勻的生成器（gen-6）、任務面板，並修好了「還原為官方星級」。

## 新內容

- **用 osu! 登入**：首頁有「用 osu! 登入」按鈕，登入後在 proj7k 水平旁邊顯示你的 7K 與 mania 總排名和 pp。登入走 osu! 官方頁面，令牌只存在你自己電腦上（`~/.proj7k/osu_account.json`），不登入就不顯示。
- **譜面生成：Mapperatorinator 後端（實驗）**：在「譜面生成」裡勾選「實驗：Mapperatorinator 模型落鍵」，就改用 [Mapperatorinator](https://github.com/OliBomby/Mapperatorinator)（OliBomby，MIT）落鍵。它是在 ranked 譜上訓練的 Whisper 類模型，節奏和鍵位一起寫。proj7k 會跑幾次，留下引擎星級最接近目標的一張。第一次勾選會下載安裝它（PyTorch 與模型權重，數 GB）到 `~/.cache/proj7k/mapperatorinator`。強烈建議有 NVIDIA 顯示卡：RTX 5060 Ti 上每首約 4 分鐘，CPU 或 Mac 會慢很多。命令列：`python3 -m proj7k.generator --backend mapperatorinator`。
- **譜面生成 gen-6：難度更均勻**：每 4 小節之間的密度拉平了，不會再出現長段幾乎空白、旁邊又是牆的情況。星級目標不變。
- **任務面板**：側欄「工具」下新增「任務」頁：所有降階、生成、匯入任務的狀態、目前進度、耗時、錯誤和產物，點開看完整記錄，排隊中的任務可取消。側欄會顯示正在執行的任務數。
- **修復「還原為官方星級」**：曲庫同步的還原現在能找到之前的備份，也不會被備份裡的雜項中斷，lazer 曲庫能正常回到官方星級。
- **文件**：README 改為英文，另有簡體與繁體中文使用說明；新增貢獻指南、行為準則、安全政策與 issue / PR 模板。

線上譜面庫 <https://7k.kaiz.dev/>（不用安裝）現在也有英文和繁體中文介面。

## 安裝或更新

**Windows 10 / 11**

1. 下載 [Release 頁面](https://github.com/ka1z07/proj7k/releases/tag/v0.2.0) Assets 裡的 **Source code (zip)**，解壓到比如 `文件\proj7k`。更新時直接解壓覆蓋原來的資料夾。
2. 雙擊 **`install.cmd`**（如果彈出「Windows 已保護你的電腦」，點「更多資訊」→「仍要執行」）。
3. 它會裝好 Python 3.14、Node.js 和相依套件，下載 proj7k 視窗，在開始選單和桌面放快捷方式，然後直接開啟。

**macOS**：解壓後在終端執行 `sh install.sh`，以後雙擊 `proj7k.command` 開啟。

需要 **osu!lazer**（不支援 stable）。完整教學見[繁體中文使用說明](https://github.com/ka1z07/proj7k/blob/main/README.zh-TW.md)。

> `proj7k-windows.exe` 和 `proj7k-macos.zip` 是 proj7k 的視窗程式本身，安裝指令碼會自動下載，一般不用手動下。單獨下載它是打不開功能的：功能在 proj7k 資料夾裡，視窗只是它的外殼。

## 已知限制

- 程式沒有程式碼簽名，Windows 第一次執行 `install.cmd` 時會提示，Mac 上由安裝指令碼處理。
- 視窗程式不會自動更新：新版本出來後，下載新的 zip 覆蓋原資料夾，再執行一次 `install.cmd` / `install.sh`。
- Linux 沒有視窗程式，`proj7k.command` 會改用 Edge / Chrome 的應用視窗或瀏覽器開啟。
- 生成和降階的譜面仍需要人看一眼再打。Mapperatorinator 在長條多的歌上星級常常偏低。Demucs 分軌是實驗功能，第一次勾選會下載數 GB。
- 任務只存在記憶體裡：重啟 proj7k 會清空任務列表，正在執行的任務暫時不能停止。
