proj7k v0.2.0 adds osu! sign-in on the home page, an experimental AI note model for the chart generator, a more even generator (gen-6), a jobs panel, and a fix for restoring official star ratings.

## What's new

- **Sign in with osu!** The home page has a *Sign in with osu!* button. Once signed in, it shows your 7K and overall mania rank and pp next to your proj7k level. The login goes through osu!'s own page; the token is stored only on your computer (`~/.proj7k/osu_account.json`) and nothing is shown until you sign in.
- **Chart generator: Mapperatorinator backend (experimental).** Tick *Experimental: Mapperatorinator notes* in the chart generator to place notes with [Mapperatorinator](https://github.com/OliBomby/Mapperatorinator) (OliBomby, MIT), a Whisper-based model trained on ranked maps, instead of proj7k's own models. proj7k runs it several times and keeps the take whose proj7k star rating is closest to your target. The first tick downloads and installs it (PyTorch and model weights, several GB) into `~/.cache/proj7k/mapperatorinator`. An NVIDIA GPU is strongly recommended: about 4 minutes per song on an RTX 5060 Ti; much slower on CPU or Mac. Command line: `python3 -m proj7k.generator --backend mapperatorinator`.
- **Chart generator gen-6: more even difficulty.** Density is now evened out between 4-measure stretches, so a chart no longer has long near-empty passages next to walls. Star targeting is unchanged.
- **Jobs panel.** A new page in the sidebar under *Tools*: every downscale, generate and import job with its status, what it is doing right now, duration, errors and outputs, the full log on click, and cancel for queued jobs. The sidebar shows how many jobs are running.
- **Fix: "Restore official stars"** in library sync now finds the backup it made and no longer aborts on stray backup entries, so your lazer library goes back to the official star ratings.
- **Docs:** the README is now in English, with Simplified and Traditional Chinese guides; contributor guide, code of conduct, security policy and issue/PR templates were added.

The online chart catalog at <https://7k.kaiz.dev/> is now available in English and Traditional Chinese too (no install needed).

## Install or update

**Windows 10 / 11**

1. Download **Source code (zip)** under Assets below and unzip it (for example to `Documents\proj7k`). To update, unzip over your existing folder.
2. Double-click **`install.cmd`**. If Windows says "Windows protected your PC", click *More info* → *Run anyway*.
3. It installs Python 3.14, Node.js and the dependencies, downloads the proj7k window, adds Start menu and desktop shortcuts, and opens it.

**macOS:** unzip, run `sh install.sh` in Terminal, then open `proj7k.command` from then on.

Requires **osu!lazer** (stable is not supported). The UI is in Chinese by default; switch to English with the toggle at the bottom left. Full guide: [README](https://github.com/ka1z07/proj7k#readme).

> `proj7k-windows.exe` and `proj7k-macos.zip` are the window itself; the install script downloads them for you. On their own they don't work: the features live in the proj7k folder, and the window is only its shell.

## Known limitations

- The programs are not code-signed: Windows warns the first time you run `install.cmd`; on Mac the install script handles it.
- The window does not update itself: for a new version, download the new zip, unzip over the folder and run `install.cmd` / `install.sh` again.
- Linux has no window build; `proj7k.command` opens the app in an Edge / Chrome app window or your browser instead.
- Generated and downscaled charts still deserve a look before you play them. Mapperatorinator output tends to come out below the target star rating on LN-heavy songs. Demucs stem separation is experimental and downloads several GB the first time.
- Jobs live in memory: restarting proj7k clears the jobs list, and running jobs cannot be stopped yet.
