# proj7k v0.3.0 釋出說明

[English](https://github.com/ka1z07/proj7k/releases/tag/v0.3.0) · [简体中文](https://github.com/ka1z07/proj7k/blob/v0.3.0/docs/releases/v0.3.0.zh-CN.md) · 繁體中文

v0.3.0 新增譜面編輯器、進步頁和直播疊加層；不同工具的任務可以同時跑，執行中的任務也能取消；譜面生成全面改用 Mapperatorinator 模型；高速疊和偏重同幾列的譜星級提高。

## 新內容

**星級有變化**（如果你把 proj7k 星級寫進了 lazer，請重新同步）

- **高速譜更難**：速度不再是線性計算，同一個配置 BPM 越高難度漲得越快；高速同指小疊（minijack）單獨計分；整張譜的星級不會遠低於它最難的 8 秒。單鍵滾鍵基本不變。
- **偏重同幾列的譜更難**：反覆壓在同幾根手指上的譜以前被低估，現在同指成本加重。
- 全部星級與段位表重新標定。如果你用過「曲庫同步」把 proj7k 星級寫進 osu!lazer，請再跑一次。降階器現在也會保持原譜的列分佈，疊譜降階後仍以疊為主。

**譜面編輯器**（側欄「工具 → 譜面編輯器」）

- 以下落式 7K 軌道顯示譜面並播放音樂，整首歌的時間軸，可按小節選擇。
- 用模型重寫任意小節：候選都會留下，先試聽試打再採用。可鎖定段落、讓某段重複（或鏡像）另一段，復原 / 重做。
- 手動修改：在吸附網格上放置、移動、刪除米鍵和長條，框選、鏡像、平移、複製；改動時星級與不可打的音符即時更新。手改過的小節，之後的模型重寫不會動。
- 可開啟任意 osu!mania 7K 譜，拆分 / 合併 / 拖動段落，把兩版並排對比並標出差異，也能讀回你在 osu!lazer 自帶編輯器裡改過的版本。
- 「匯入 osu!」把當前這一版作為新譜匯入 lazer（不覆蓋任何譜）；「開啟資料夾」開啟專案資料夾。

**譜面生成**

- **全面改用 Mapperatorinator 落鍵**：去掉了 proj7k 自己的落鍵模型（以及 Demucs 分軌）；第一次生成時下載模型（數 GB，強烈建議有 NVIDIA 顯示卡）。
- **修好長條**：以前重疊的長條和長條和絃會被合併成一根，長條譜因此簡單得多（比如本應 7.5★ 只有 2.6★）。現在長條歌大約在 7–8★。
- **技法配比**：給關心的技法池拉一個星級範圍，生成時留下最貼近這些範圍的一張，降階器再把每個池修到各自的範圍裡。
- **更快、更連貫**：不寫 SV，有參考譜時借用它的 timing，可選快速模式（約快一倍，銜接處偶有空白），歌裡重複的段落會複用同一個樂句，空白段會補寫，重疊音符會清理。生成的譜全程同一流速。
- **段落**：每次生成存成專案，按 8 小節分段，可單獨重寫、鎖定和錨定。
- **長條 LoRA（實驗，預設關閉）**：針對長條歌微調的模型，長條譜更難，但混合歌會多寫長條。
- 檔名含中文等非 ASCII 字元的音訊現在能正常解碼。

**降階器**

- **按技法範圍降階**：給每個池一個星級範圍，降階器把超出上限的池降下來、守住到了下限的池，同時達到總目標。
- 批次提交：一次生成整條階梯（目標段位及以下 N 檔）。

**面板與任務**

- **任務並行**：不同工具（降階、生成、lazer、profiler）的任務可以同時跑，絕不會有兩個任務同時寫同一個資料庫。降階和生成頁各有自己的佇列，可以連續提交。
- **取消執行中的任務**：執行中的任務會在下一個安全點停下（絕不會在寫 lazer 曲庫或資料庫的半途中斷），模型程序立即停止。
- **設定頁**：語言、動畫開關、懸停提示、任務結束提醒（角落提示、提示音、系統通知）、預設輸出資料夾、預設打包 .osz / 加入 lazer 收藏夾、記住每個工具上次的選項。
- **進步頁**（側欄「進步」）：目標段位、總體與各技能的差距和按當前速度的預計，總體曲線與各技能小圖。
- **打崩之後**，proj7k 會指出崩在哪裡，並給出低一檔的練習譜、回放診斷或直接看這一局（可在設定裡關閉）。
- **直播疊加層**：給 OBS 或側邊視窗用的透明卡片，跟隨你正在打的譜，顯示星級、段位、各技能與你水平的對比和個人最好。在設定頁生成並複製它的地址。
- 各處任務計時即時跳動，每個控制元件都有懸停提示，回放檢視器新增音量滑桿（每臺電腦分別記住）。

線上譜面庫 <https://7k.kaiz.dev/> 現在每頁有自己的標題、摘要和 sitemap，方便搜尋引擎收錄。

## 安裝或更新

**Windows 10 / 11**

1. 下載 [Release 頁面](https://github.com/ka1z07/proj7k/releases/tag/v0.3.0) Assets 裡的 **Source code (zip)**，解壓到比如 `文件\proj7k`。更新時直接解壓覆蓋原來的資料夾。
2. 雙擊 **`install.cmd`**（如果彈出「Windows 已保護你的電腦」，點「更多資訊」→「仍要執行」）。
3. 它會裝好 Python 3.14、Node.js 和依賴，下載 proj7k 視窗，在開始選單和桌面放快捷方式，然後直接開啟。

**macOS**：解壓後在終端執行 `sh install.sh`，以後雙擊 `proj7k.command` 開啟。

需要 **osu!lazer**（不支援 stable）。完整教程見[中文使用說明](https://github.com/ka1z07/proj7k/blob/main/README.zh-TW.md)。

> `proj7k-windows.exe` 和 `proj7k-macos.zip` 是 proj7k 的視窗程式本身，安裝指令碼會自動下載，一般不用手動下。單獨下載它是打不開功能的：功能在 proj7k 資料夾裡，視窗只是它的外殼。

## 已知限制

- 星級與 v0.2.0 不同（見上）；如果你把 proj7k 星級寫進了 lazer，請重新跑一次「曲庫同步」。
- 譜面生成需要 Mapperatorinator 模型（數 GB），沒有 NVIDIA 顯示卡會很慢。高難度長條歌生成的譜仍低於同曲人工譜，生成的譜面仍需要人看一眼再打。
- 程式沒有程式碼簽名，Windows 第一次執行 `install.cmd` 時會提示，Mac 上由安裝指令碼處理。
- 視窗程式不會自動更新：新版本出來後，下載新的 zip 覆蓋原資料夾，再執行一次 `install.cmd` / `install.sh`。
- Linux 沒有視窗程式，`proj7k.command` 會改用 Edge / Chrome 的應用視窗或瀏覽器開啟。
- 任務只存在記憶體裡：重啟 proj7k 會清空任務列表。
