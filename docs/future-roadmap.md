# om7k 工具链：远期架构设计与演进路线图（Future Roadmap）

## 一、系统愿景与总体宗旨

本项目（`proj7k`）致力于为 **osu!mania 7K（om7k）** 玩家生态构建一套完备的体验与训练工具链：
1. **重构难度评判体系**：从底层物理与认知第一性原理出发，推翻官方失衡的 Star Rating (SR) / pp 逻辑，建立纯客观、多维度的铺面固有难度引擎；
2. **多维技法逻辑检索**：使玩家能够脱离模糊的单一星级，按照具体技法考点与细分难度精准检索全量 om7k 曲库；
3. **数据驱动的深度诊断**：基于玩家 `.osr` 回放数据深入解构击键时序与 LN 尾判缺陷；
4. **训练反馈闭环**：结合玩家能力画像与弱项归因，提供科学的进阶训练建议，实现从“盲目刷图”到“精准提升”的跨越。

### 1. 核心计算引擎层（Core Engine）
- **客观物理性**：严格遵守 [ADR-0001](adr/0001-decouple-intrinsic-difficulty-from-player-data.md)，难度只由谱面本身决定，与玩家成绩无任何关联。
- **技法多维化**：遵循 [ADR-0002](adr/0002-jinjin-dan-as-canonical-technique-benchmark.md)，以 Jinjin 7K Dan 闭环体系为度量衡，输出多维能力雷达（如：叠 Jack、技 Tech、乱 Stream、切 Chordstream、LN 密度、反键 Inverse、释放 Release 等），绝不压制为单一标量。
- **高移植性**：以跨平台底层语言开发，支持编译为服务端守护进程、本地 CLI、以及 WebAssembly (WASM)。

### 2. Web 云端社群平台（Web Platform）
- **曲库集中同步**：规避 osu!lazer 本地数据库加密问题，通过服务端定时爬虫与 osu! API 定向抓取并解析全量 7k 专有谱面。
- **逻辑检索系统**：提供直观的可视化筛选器，允许玩家输入如“Chordjack 相当于 Jinjin 6th Dan，但 LN 释放要求低于 4th Dan”的复杂复合技法检索。
- **玩家档案与云端偏好**：支持玩家关联 osu! 账号，上传回放数据进行云端多维能力画像展示。

### 3. 本地回放分析与缺陷诊断工具（Local Analyzer）
- **双端回放兼容**：无缝解析 osu!stable 与 osu!lazer 的 `.osr` 文件。
- **微观时序重构**：将每一按键的击键时差绘制为离散分布图，量化手指各轨道的独立性差异与主从手力量失衡。
- **LN 尾判专用通道**：专门剖析长条释放点（Tail Release）的时间窗分布，诊断玩家“粘键”、“提前放手”等隐性问题。
- **硬件级数据探索**：预留驱动级键盘采样输入接口（如 1000Hz / 8000Hz 原始时钟数据），探索硬件响应对 7k 高难读谱与腱力的真实影响。

### 4. 自适应训练与反馈闭环（Adaptive Training Loop）
- **弱项自动归因**：结合玩家多局打图数据，智能定位当前瓶颈（如：“八段 Marathon 未通过主要是 Stage 1 的 170BPM Chordjack 腱力不足导致 Stage 2 提前力竭”）。
- **靶向推图**：根据诊断结论，从云端曲库自动召回匹配当前突破梯度的练习谱面。
