# 0025. 降阶器的「只追难度」模式

- **状态**：accepted（2026-10-08；扩展 ADR-0011 与 ADR-0021 的降阶器）。
- **背景**：降阶器默认保留原谱的主技法：双闸门要求八项技法星级向量余弦 ≥ 0.80 且主技法不变，选删音符时还会对主技法承担的音符打折扣。有的谱（实测 120 张标杆谱降到 0th 时有 18 张，多为高段的 speed / stamina 谱与 LN 谱）在保留主技法的前提下降不到目标：再删，主技法就让位给别的技法，闭环只好停在目标之上。玩家想要的是一张目标难度附近、仍然像样的练习谱，主技法是否保留并不在意。

## 决策内容

1. **新模式 `free`（只追难度）。** `DownscaleOptions(preserve_technique=False)`，命令行 `--mode free`，控制台降阶页「降阶方式 → 只追难度」。默认仍是 `technique`（保留主技法），已有行为不变。
2. **free 模式放掉的只有技法约束。** 不再执行第一道闸门（余弦与主技法，结果里照常报告），不执行第二道闸门里按长条比例判断谱面类别的几条，选删时不再对主技法音符打折扣；练习谱的版本名与标签不带主技法（`[P-3rd] …`，无 `dominant_*`）。
3. **合理性约束照旧，并加一条。** 纯删除、强拍与和弦骨架、左右手负荷平衡、至少 5 个物件都不变；另加「不删出新空白」：练习谱任意两个相邻物件时刻之间的空白，不得比原谱在这段里最长的空白再长出一小节以上（`validator.longest_new_silence`）。这一条只在 free 模式下执行，保留技法模式的结果不变。
4. **保留技法降不到目标时提示。** 当保留技法模式是被技法闸门挡住（`PruningResult.stopped_by_validation`）且星级停在目标容差之上时，`DownscaleResult.suggest_free_mode` 为真：命令行报告末尾提示改用 `--mode free`，JSON 带 `suggest_free_mode`，控制台结果卡给出说明与「改用只追难度重新降阶」按钮。因候选耗尽或迭代用完而停下时不提示，因为 free 模式同样会停在那里。

## 后果

- 提示只说明 free 模式可能降得更低，不预先跑一遍 free 模式验证；控制台上一键即可重跑。
- free 模式下主技法常会换成别的技法（标杆谱里多为 speed / stamina 换成 tech 或 jack，LN 谱换成另一种 LN 技法），这是这个模式的本意。同一批 18 张里，free 模式有 17 张降到目标容差以内。
