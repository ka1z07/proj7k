# 0027. 从音频生成 7K 谱面

- **状态**：accepted（2026-10-10；Kai 选定「从音频出谱」路线，设计说明见项目里的「从音频出谱：7K 谱面生成器设计说明」）。
- **背景**：工具链能评难度（引擎）、能把已有谱降阶（ADR-0021/0025），但不能从一首歌出一张新谱。玩家想要的是：任意一首歌，指定段位或星级，得到一张节奏跟着音乐、能打、难度准的 7K 谱。

## 决策内容

1. **新包 `proj7k.generator`，第一版只出米键。** 流水线：解码 → 起音强度 → 节拍网格 → 选点 → 配键 → 引擎打分，星级不达标就调强度重来。长条要判断「音持续多久」，放到后面。
2. **解码不引入重依赖。** `.wav` 用标准库读；mp3/ogg/flac 用 `miniaudio`（单个 wheel，没有系统库，Windows 与 Python 3.14 都有现成包）；都不行时用 PATH 上的 `ffmpeg`。不用 librosa（依赖 numba，在 Python 3.14 上装不上的风险太大）。分析只用 numpy/scipy，统一 24 kHz、10 ms 一帧。
3. **起音**（`onset.py`）：对数幅度谱的正向增量（上一帧做 3 格频率最大值滤波，抑制颤音），分低（< 200 Hz）、中、高（≥ 3 kHz）三段各自归一，再合成总强度；另记新增能量所在的频率位置（亮度）与每帧响度。整首歌只归一一次，所以副歌比前奏密。峰值相对真实起音的偏差在合成鼓上实测为 −9 ms，已扣除。
4. **Timing 三个来源，优先级从高到低**：参考谱面的全部非继承 timing point（`--timing-from`，可变速）→ 手动 `--bpm/--offset` → 自动测速。自动测速只给恒定 BPM：自相关加倍数梳子、以 170 BPM 为中心的先验选周期，±2 % 内以 0.01 BPM 步长折叠包络、取最尖锐的一个，低频最强的那一拍当强拍；把歌分四段各自定相位，相差超过 25 ms 就提示可能变速。
5. **网格**（`grid.py`）：每拍按音乐实际用的细分选二分（1/2、1/4）或三分（1/3），逐拍决定；每个点取附近（八分之一拍、至多 25 ms）最强起音的强度、三段强度与亮度，响度低于 −38 dB 的点算静音、不放音符。
6. **一个旋钮「强度」x 管密度与押数**（`generate.py`）。网格点的强度加上拍位加成（强拍 0.30、拍 0.18、半拍 0.06）达到 `1 − x` 才放音符；押数按权重排名分配，使平均每行 `1 + min(1.8, 0.6x)` 个音符。x 超过 1.6 后弱起音门槛逐步放开，忙的目标可以把一段的空网格点补成连续的 stream。星级随 x 单调上升，二分 x 直到落进目标 ±0.10★；落不进时报告最高能到多少星，或最接近的星级。
7. **配键**（`columns.py`）：逐行在所有列组合（7K 至多 35 种）里取代价最低的。代价含：同列间隔的平方反比（75 ms 约 6，300 ms 约 0.4）、两手近期负荷（0.5 s 衰减，拇指列各算半）、亮度在全曲中的排名决定的偏好位置（低音偏左、高音偏右）、三押以上全在一只手、与上一行完全相同，以及一个按种子的小随机项。引擎星级读的是持续负荷，对单列过载几乎看不见（见降阶器的爆发问题），所以「别让一列连打」由配键自己保证，不靠星级闭环。
8. **输出与降阶器一致**：`.osu`（版本名 `Gen <目标> (<星级>)`，Tags 带 `proj7k gen-1 seed<n>`）和带音频、背景的 `.osz`；有参考谱面时沿用它的 General、Metadata（`BeatmapID` 置 0）与背景。命令行 `python3 -m proj7k.generator`，控制台「谱面生成」页（`generate` 任务），默认用游戏当前谱面的歌并借用其 timing。
9. **评测**（`python3 -m proj7k.generator.evaluate`）：对带音频的人写 7K 谱，用它的 timing、在它的引擎星级上生成，比较行时刻（±20 ms）的精确率与召回率和星级误差；再单独自动测速，与谱面主 BPM 比（准确 / 差一个八度 / 错）以及相位误差。来源是 osu!stable 的 Songs 文件夹、解压的 .osz，或 osu!lazer 曲库（只读）。

## 后果

- 合成鼓（已知每个起音）上：120–225 BPM 的 BPM 与相位都测准；230 BPM 以上测成一半，115 BPM 以下测成两倍。生成谱在 1.5–7.9★ 都能落进 ±0.1★，低目标时 95 % 以上的行在真实起音 20 ms 以内。真实歌曲上的表现要用评测工具在 Kai 的曲库上测，参数（加成、阈值、代价权重）据此再调。
- 参数都是常数，改它们不动引擎，不影响星级指纹与护栏。
- 后续：长条（持续音）；用谱面库下载的 .osz（音频 + 人写谱）学选点、押数与谱师风格（设计说明第 3 阶段）。
