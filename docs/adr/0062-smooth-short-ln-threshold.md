# 0062. 短 LN 的判定从硬门槛改为平滑过渡

- **状态**：proposed（2026-11-16；改引擎常数与形式，修订规格 §2.2；Kai 选定「平滑过渡」）。
- **背景**：Kai 发现「Duplicity Shade [Metamorphosis]」（MWC 2022 TB，beatmap 3469849）0.75x 读 11.51★，0.76x 只有 11.08★，0.77x 10.55★，变快反而变简单。原因是 §2.2 的 `l_min = 100 ms`：实际时长短于 100 ms 的 LN 当作米。变速把整张谱的时间拉伸，这张谱 4276 根 LN 里有 2908 根短于 150 ms（集中在 65/66、76–78、98 ms），放慢时一批批越过 100 ms 变成 LN、多出松手事件，加快时又一批批掉回米，星级跟着跳。标杆谱里 80 张 LN 谱有 52 张在 0.5–1.5x 之间出现倒挂，最大一步跌 1.33★。

## 决策内容

1. **LN 程度 `g`**（`engine/events.py:ln_weight`，`params.l_min/l_full`）：实际长度 ≤ 80 ms 为 0（米），≥ 120 ms 为 1（完整 LN），中间是 smoothstep。`l_min = l_full` 时就是原来的硬门槛（`params.V02` 取 100/100，金标准不变）。
2. **`g` 进入引擎的每一处**，使 `g → 0` 时读数连续地回到米、`g → 1` 时回到 LN：
   - 每个事件带权重 `wt`：按下为 1，部分 LN 的松手为 `g`。总难度、爆发窗口、八个技法的求解都按 `wt` 加权；LN 语境 λ 的均值、覆盖率、主导份额也按 `wt` 加权。
   - 松手事件的需求 `ω = w_rel · g`；手累加器在只有部分松手的行上按 `g` 部分更新（状态和时间戳都按 `g` 插值）。
   - λ 的 LN 项、q_release / isolated 乘 `g`；`held` 取持有 LN 的 `g`（浮点），`h` 随之连续。
   - 同列下一个按下的 `j`：上一个物件的结束时间在米（头 + δ_h）与 LN（尾）之间按 `g` 插值；`last` 在松手处记为「头 + g · 长度」。
3. **区间选 80–120 ms**：比较了 60–140、80–140、100–160、70–100、90–110、80–120。各区间的倍速单调性相近（倒挂的 LN 谱 52 → 10–24 张），区间越窄对 1.0x 的改动越小但越不平滑；80–120 在两者之间，对段位阶梯的伤害最小。
4. **画像与降阶器**按同一权重读：`ChartField.wt`；画像的已玩事件乘 `wt`；`ChartField.eps_total`、`share`、降阶器的超额损失按 `wt`。特征标签（`patterns.py`）仍把任何 `g > 0` 的物件当 LN 读按住。

## 后果

- **倍速单调性**：80 张 LN 标杆谱在 0.5–1.5x（步长 0.02）中有倒挂的从 52 张降到 12 张，最大一步跌幅 1.33★ → 0.31★。合成谱（76 ms LN 交替的 180 BPM 流）在 0.70–0.85x 严格递增，`tests/engine/test_engine_ln_ramp.py` 钉住。
- **余下的倒挂来自别的部件**，本 ADR 不处理：`row_tol = 1 ms` 的行合并（偏 1 ms 的音在快速率下并成一行，例：LN Release 6th 1.44x −0.33★）；按秒定的窗口（`delta_0` 的 2 秒中位数、爆发窗口每 2 秒一步）随谱长伸缩时的取样跳动（例：LN Inverse 3rd 每隔约 0.16x 跌 0.1–0.2★）。
- **1.0x 的星级**：只有含 80–120 ms LN 的谱会动；Regular 四个池不变（`STAR_A/B` 不变）。60 张 LN 谱均值 +0.01★，54 张在 ±0.3★ 内，最大 +0.40 / −0.45★（LN General 7th 6.91 → 6.46，消掉了它高于 8th 的倒挂）。
- **阶梯**：总星级阶梯照常通过；自有技能倒挂 22 → 21（LN Tech 4 → 3）；LN General 自有技能 τ .885 → .942、LN Tech .885 → .923；主导技法 LN General 9 → 10、LN Inverse 12 → 13；本池技法最高 LN General 7 → 8。
- **需要 Kai 裁定的放宽**：LN Release 自有技能 τ .771 → .752（ρ .885 → .867）；本池技法最高 LN Tech 13 → 10；主导技法 LN Tech 5 → 4、LN Release 12 → 10；Stellium 八池中位数 13.08，区间上限 13.0 → 13.5。
- 重拟合：`SKILL_SCALE`/`SKILL_EXPECT`（LN 四项）、`burst.ENVELOPES`；星级指纹更新。引擎版本号自动变化；lazer 星级需要重新同步，目录需要重新入库。引擎 pp（ADR-0061）的变速成绩随之连续。
