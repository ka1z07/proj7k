# 0003. 产品形态：Web 云端社群平台 + 本地回放分析工具

om7k 工具链采用“Web 云端社群平台为主（曲库同步与多维检索）+ 轻量本地工具为辅（回放深度分析）”的分层混合架构。

## 决策背景

1. **客户端限制**：由于 osu!stable 与 osu!lazer 存在显著版本差异，不存在能够完美兼容两者的本地桌面端曲库管理工具；且 osu!lazer 本地曲库与数据库采用非公开加密存储方式，本地直接扫盘读取存在巨大技术壁垒。
2. **检索需求**：为了实现玩家按指定技法与难度精准检索曲库，需要一个集中化索引的云端数据库，通过 osu! OAuth 或定向爬虫同步全量 om7k 谱面。
3. **数据诊断**：玩家在打完图后需要对个人游玩缺陷进行仔细剖析，需要本地工具直接读取 `.osr` 回放数据（覆盖 stable 与 lazer），并为未来探索底层高频键盘击键时序预留独立分析通道。

## 方案取舍

- **被拒绝的方案**：纯本地桌面客户端（如单体 Electron/Tauri 统一管理曲库与回放）。
- **被拒绝的方案**：纯云端平台（每次深度回放分析需上传大容量时序数据，交互迟滞且受网络影响）。
- **采纳的方案**：
  - **Web 云端平台**：承载 7k 专有曲库、多维技法检索标签索引、社区水平分布与玩家授权数据同步。
  - **本地分析工具**：专注于玩家单局/多局 `.osr` 回放时序偏差、LN 尾判精度分析及缺陷归因。

## 架构影响

核心计算引擎（谱面解析、物理特征提取、时序度量）作为底层独立抽象库设计，既能通过服务端运行在 Web 平台，又能编译供本地工具调用。
