# 0031. 生成器按乐曲结构写谱

- **状态**：accepted（2026-10-17；Kai 试了 gen-2 后：「不会分辨乐曲的结构，写谱写得太满，一首歌不同地方应该有不同的配置；现在基本是 1/16 所有节拍填满，非常无趣」）。取代 ADR-0027 第 7 条（选点与押数）。 **已被 ADR-0046 取代（2026-10-28，段落切分删除）。**
- **背景**：选点是一个阈值：网格点的起音强度加拍位加成过了 `1 − x` 就放音符。强度 x 超过 1 以后阈值变成负数，所有不静音的网格点都会被选上，再往上只能靠押数和「补满弱拍」堆星级。6–7★ 的目标在 Kai 的三首试曲上 x 都在 1.1–1.4，于是整首歌每个 1/16 都是音符：每 16 拍的行数变异系数只有 0.03–0.05，而 ranked 谱在每个星级都是 0.25–0.32。人写谱的密度跟着段落走，副歌满、主歌轻、间奏留白。

## 决策内容

1. **先切段落**（`generator/structure.py`）。每小节取响度（上四分位，dB）与三段起音强度，各自在全曲做 z 分数。小节自相似矩阵上用 4 小节棋盘核算新奇度（Foote），另加前后 4 小节响度均值之差（只变响不变音色的 drop 也算边界）；高于均值的峰作边界，段落至少 4 小节，离 4 的倍数一小节以内就挪到 4 的倍数上。段落均值特征（按段落再做 z 分数）距离 ≤ 0.8 的同标签。能量：响度与起音 z 分数的均值，同标签取平均，按小节数加权排名到 0..1；各段响度相差不到 6 dB 时向 0.5 收拢（一首从头到尾一个样的歌不该被排名硬拉出副歌）。
2. **每段按能量分配密度**（`generate.select_rows`）。最响的段取 `min(x, 1)` 比例的非静音网格点，最安静的段取它的 45 %（`QUIET_SHARE`），中间线性。段内按起音强度加拍位加成排序取最强的。几乎没有起音的网格点（< 0.06）只有在 x ≥ 1 且能量 ≥ 0.6 的段里才会被补成 stream。押数随 x 平滑增加（每行平均额外音符 x ≤ 1 时 0.45x，到 x = 2.5 时 1.35，之后更快，上限 2.2），并按段能量放大或缩小（`0.5 + e` 倍），副歌和弦多、主歌单键多。x 超过 2.5（`SPREAD_FROM`）后安静段的密度也逐步补到和最响段一样，弱起音点全都放开，到 `X_MAX = 3.5` 时全曲填满：高星目标牺牲一部分段落对比，换来能到达。
3. **每段一种键型倾向**（`patterns.STYLES`、`structure.section_styles`）。plain（模型原样）、flow（楼梯，对数权重 +1.2）、trill（与前前一行相同，+0.8）、jack（与前一行有共同列，+1.0）。同标签的段落用同一种（副歌回来时写法一样），相邻段落尽量不同；能量 < 0.5 的段不抽 jack。倾向只是乘在人写谱模型的概率上，不会写出人写谱里没有的东西。最初定为 +2.0/+1.5/+2.0，第一轮评测里颤与半拍内叠都是人写的 2–3 倍，减弱。
4. 版本号 `gen-3`。评测的键型统计增加 `density_cv`（每 16 拍行数的变异系数）、`quarter`、`triplet`（落在 1/4、1/3 拍上的行的比例）。

## 后果

- 三首试曲（6.5★）：每 16 拍行数变异系数 0.03–0.05 → 0.21–0.27；平均每行音符 2.09–2.44（ranked 6–7★ 谱 2.14–2.24）；4.0★ 时 1.40–1.50（ranked 4★ 1.74）。
- 段落切分与能量只看音频，没有在人写谱上验证过切得对不对；一首歌只有前后音色、响度都变时才切得出来。
- 第一轮（Kai 曲库 40 首，每首一个难度，强度上限 3、密度在最响段填满后只靠加宽和弦）：每 16 拍行数变异系数中位 0.274（人写 0.323），1/4 拍行占比 0.273（0.241），精确率 0.793、召回率 0.651（gen-2 0.694 / 0.859），不再满屏 1/16。但星级上限塌了：三首试曲最高 6.7–7.7★（gen-2 9.0–12.2★），40 首里 16 首离人写谱星级超过 0.5★，集中在 Stellium 以上与 LN 谱。改为上面第 2 条的分段增长后，三首试曲上限 11.8–14.0★，6.5★ 时变异系数 0.21–0.27、8★ 时 0.15–0.24。颤 0.137（人写 0.044）、半拍内叠 0.166（0.062）、键型重复 0.217（0.083）偏多，三连音 0.008（0.028）偏少；整小节节奏重复 0.112，只有人写 0.214 的一半。
- 第二轮（同一批 40 首，`8b5210b`）：星级误差中位 0.094 → 0.047，离人写谱超过 0.5★ 的 16 → 3 首（剩下的是 FLN 与速度练习谱：Inverse Brackets FLN 10.33 → 9.40、Bambi 8.87 → 7.81、Speed Practice 3rd 5.29 → 4.68），精确率 0.788、召回率 0.714。每 16 拍行数变异系数 0.247（人写 0.323），1/4 拍行占比 0.300（0.241）。键型统计没有靠近人写：颤 0.129、半拍内叠 0.192、键型重复 0.211、整小节节奏重复 0.107，留待 Kai 试打后再调。
- 引擎不变，星级指纹与护栏不受影响。
