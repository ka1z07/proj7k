# 0050. 谱面编辑器与技法星级范围

- **状态**：accepted（2026-10-31；Kai：「每个技法应该可以具体输入难度范围，或用滑杆调整……应该要有如回放器一般的页面以供用户直观的修改」）。补充 ADR-0047（生成工程、段落、技法配比）。设计稿：<https://claude.ai/artifact/2qR2nVpjuQvxCY7ohqpA6Q>
- **背景**：生成之后能改的只有生成页里的一张段落表：按 8 小节一段勾选、重写后自动留下分数最好的一个候选，看不到谱面也听不到。技法配比每池只有「少 / 照常 / 多」三档。

## 决策

分三期做，本 ADR 记第一期，后两期做完再补。

1. **技法星级范围。** 配比的每个池可以是原来的倾向（-1..1），也可以是一个星级范围 `(下限, 上限)`，任一头可空。命令行写 `rc_jack=4.5..6`、`rc_speed=..5`、`rc_tech=3..`（`4.5-6` 也行），工程文件与页面用 `[下限, 上限]`。
   - 挑选：每次生成（或候选）的分数加上 `mix.penalty` = 各池落在范围外的星数之和 − 倾向分。
   - 降难：`mix.skill_weights(mix, profile)` 把高于上限的池权重设 -1（先删），低于下限或刚到下限的设 +1（最后删）。
   - 补不上：低于下限的池只能靠多跑几次碰运气。结果的警告与候选里写明「Jack 要 ≥ 6★，实际 4.8★」（`mix.misses` / `miss_text`）。
   - 界面：生成页和编辑器共用 `P7.mixControl()`，每池一根双头滑杆（0–15★）加两个数字框，留空 = 不限；轨道上金线是现在的值。
2. **按小节重写与候选试听。** `project.rewrite` 除了段落编号，还收 `bars=(首, 末)`（小节从 0 数，与段落一致），碰到锁定或锚定的段就拒绝。`audition=True` 时不出新版本：所有候选按分数排好写成 `.p7kgen-work/candidates/*.osu`，记在工程的 `candidates` 里；`adopt(k)` 把第 k 个变成新版本，`discard` 全部丢掉。当前版本一变（新版本、撤销/重做），候选作废并删除文件。命令行 `rewrite --bars 9-16 --audition`、`adopt N`、`discard`；看板任务 `generator_project` 的 `op` 多了 `adopt`、`discard`，`rewrite` 多了 `bars`、`audition`。
3. **谱面编辑器页面 `/editor`**（侧栏「工具 → 谱面编辑器」，桌面端同一页）。左边是下落式 7 列谱面（配色与回放查看器相同，默认暂停，滚轮按拍滚动，空格播放，音频与谱面同一时钟），左侧小节号与段落条；下边是整首时间轴（每小节密度、按星级上色的段落、金色锁定、紫色锚定）；右边是选区信息（星级、八池）、重写表单（目标星级、候选数、长条比例、技法范围）、候选列表、段落操作。在时间轴或小节号上拖动选小节；点候选就把它画进谱面（淡紫色），从选区前一小节开始播放；满意点「采用」。
   - 读数据走只读 HTTP：`/api/editor/projects`（看板生成目录下的工程，新的在前）、`project`、`stretch`（一段的星级与八池）、`audio`（带字节范围）。`path` 必须是存在的 `.p7kgen.json` 文件，别的文件一律 404。改动都走现有的任务队列（`generator_project`），可取消（ADR-0049）。

## 后两期

- **第二期：手动编辑。** 在谱面上放、拖、删米键与长条，吸附网格 1/1–1/16，框选后镜像、平移、复制粘贴，页内撤销；实时八池星级与非法音符标红；保存为工程的新版本，手改过的小节自动锁定。
- **第三期：打磨。** 打开任意 7K .osu 建工程（官方谱也能拿来改）、拖动段落边界、两版并排对照、从 lazer 编辑器读回（ADR-0047 第 5 阶段）。

## 后果

- 范围不是保证：模型写不出的技法加不出来，界面与日志都直说。八池互相牵连（加 Jack 常带着加 Stamina），范围给得太窄或互相矛盾时会一直达不到。
- 候选文件只在试听期间存在；工程文件多了一个 `candidates` 字段（旧工程读进来是空列表）。
- 编辑器的绘制代码是回放查看器的精简版，没有抽成共用文件：回放查看器是写到磁盘上、可以直接用 file:// 打开的独立页面，不能引用看板的脚本。
- 测试：`tests/test_generator_project.py`（按小节重写、锁定段拒绝、试听/采用/放弃、换版本后候选作废、编辑器数据）、`tests/test_generator_mix.py`（范围的写法、打分、降难权重、按范围挑候选）、`tests/test_dashboard.py`（编辑器 API、只开工程文件、试听与采用的任务）。
