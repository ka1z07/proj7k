# 0050. 谱面编辑器与技法星级范围

- **状态**：accepted（2026-10-31；Kai：「每个技法应该可以具体输入难度范围，或用滑杆调整……应该要有如回放器一般的页面以供用户直观的修改」）。补充 ADR-0047（生成工程、段落、技法配比）。设计稿：<https://claude.ai/artifact/2qR2nVpjuQvxCY7ohqpA6Q>
- **背景**：生成之后能改的只有生成页里的一张段落表：按 8 小节一段勾选、重写后自动留下分数最好的一个候选，看不到谱面也听不到。技法配比每池只有「少 / 照常 / 多」三档。

## 决策

分三期做。第一期（下面 1–3）2026-10-31 合入；第二、三期（4–5）Kai 2026-11-01 选「2+3 一起开发」，同一 PR 补上。

1. **技法星级范围。** 配比的每个池可以是原来的倾向（-1..1），也可以是一个星级范围 `(下限, 上限)`，任一头可空。命令行写 `rc_jack=4.5..6`、`rc_speed=..5`、`rc_tech=3..`（`4.5-6` 也行），工程文件与页面用 `[下限, 上限]`。
   - 挑选：每次生成（或候选）的分数加上 `mix.penalty` = 各池落在范围外的星数之和 − 倾向分。
   - 降难：`mix.skill_weights(mix, profile)` 把高于上限的池权重设 -1（先删），低于下限或刚到下限的设 +1（最后删）。
   - 补不上：低于下限的池只能靠多跑几次碰运气。结果的警告与候选里写明「Jack 要 ≥ 6★，实际 4.8★」（`mix.misses` / `miss_text`）。
   - 界面：生成页和编辑器共用 `P7.mixControl()`，每池一根双头滑杆（0–15★）加两个数字框，留空 = 不限；轨道上金线是现在的值。
2. **按小节重写与候选试听。** `project.rewrite` 除了段落编号，还收 `bars=(首, 末)`（小节从 0 数，与段落一致），碰到锁定或锚定的段就拒绝。`audition=True` 时不出新版本：所有候选按分数排好写成 `.p7kgen-work/candidates/*.osu`，记在工程的 `candidates` 里；`adopt(k)` 把第 k 个变成新版本，`discard` 全部丢掉。当前版本一变（新版本、撤销/重做），候选作废并删除文件。命令行 `rewrite --bars 9-16 --audition`、`adopt N`、`discard`；看板任务 `generator_project` 的 `op` 多了 `adopt`、`discard`，`rewrite` 多了 `bars`、`audition`。
3. **谱面编辑器页面 `/editor`**（侧栏「工具 → 谱面编辑器」，桌面端同一页）。左边是下落式 7 列谱面（配色与回放查看器相同，默认暂停，滚轮按拍滚动，空格播放，音频与谱面同一时钟），左侧小节号与段落条；下边是整首时间轴（每小节密度、按星级上色的段落、金色锁定、紫色锚定）；右边是选区信息（星级、八池）、重写表单（目标星级、候选数、长条比例、技法范围）、候选列表、段落操作。在时间轴或小节号上拖动选小节；点候选就把它画进谱面（淡紫色），从选区前一小节开始播放；满意点「采用」。
   - 读数据走只读 HTTP：`/api/editor/projects`（看板生成目录下的工程，新的在前）、`project`、`stretch`（一段的星级与八池）、`audio`（带字节范围）。`path` 必须是存在的 `.p7kgen.json` 文件，别的文件一律 404。改动都走现有的任务队列（`generator_project`），可取消（ADR-0049）。

4. **第二期：手动编辑。** 编辑器左上角四个工具（1 选择、2 米键、3 长条、4 删除；右键也是删），吸附 1/1–1/16（按所在红线的拍长）。选择工具：点选、Shift 加选、拖动移动（列与时间一起）、拖长条尾巴改长度、拖空白框选；Ctrl+A 全选选区、H 镜像、←/→ 平移列、↑/↓ 挪一格、T 米键/长条互换、Ctrl+C/Ctrl+V 复制到判定线、Delete 删、Ctrl+Z/Ctrl+Y 页内撤销（与工程的上一版/下一版分开）。
   - 实时读数：每次改动 350 ms 后经 WebSocket `editor_rate` 把整张谱交给 `project.rate_rows`，回来整首星级、八池、选区那段的星级与 `legal.problems`；不能玩的音符（同列重叠、压在长条里、零长长条）画成红色，有红色就不能保存。
   - 保存：「保存为新一版」走 `generator_project` 的 `op=edit`（`notes` 是 `[列, 头, 尾或 null]` 的列表），后端 `project.edit` 再查一遍合法性、拒绝没有变化的保存，把与当前版不同的小节记进工程的 `hand_bars`，版本备注「手改第 x–y 小节」。手改小节绿色；之后的模型重写碰到它们就拒绝（`_stretch`），解锁所在段才放开。被手改到的锚定段解开锚定（否则下次同步会把手改冲掉）。
   - 小节归属：.osu 的时间是整毫秒，小节起点不是；离小节线 2 ms 以内的音符算这一小节的（`BAR_SLACK_MS`）。
   - 有没保存的手改时，换版本、看候选、重写、段落操作、换项目都先拦住（换项目与打开别的谱会问一句），离开页面浏览器会提示。
5. **第三期：打开任意谱、段落边界、对照、读回。**
   - 打开谱面：顶栏「打开谱面…」填 .osu 路径、谱面 ID、链接，或「用游戏当前谱面」，跑任务 `editor_open`（只占生成器资源）。`project.open_chart` 只收 mania 7K，把 .osu（BeatmapID 0、BeatmapSetID -1）、音频、背景复制到看板生成目录的 `edits/<谱名>[ (k)]/`，原谱一个字节不动；导入 osu! 是一张新谱。命令行 `python -m proj7k.generator.project --open CHART.osu [OUT_DIR]`。
   - 段落：「从选区起点拆开」（`op=split`，`section`、`bar` 从 1 数）、「和下一段合并」（`op=merge`），以及在时间轴底部段落条上拖分界线（`op=boundary`）。都经 `project.set_boundaries`：新段落里每个小节原来都锁定才算锁定；锚定只留给起止都没变的段，编号按新段落重排；没有新版本，只改段落。
   - 对照：顶栏「对照」选另一版（`/api/editor/take?n=`），在右边并排画；左边多出的音符绿色、右边少了的红色。
   - lazer 读回：「查找 osu!lazer 里改过的版本」（`/api/editor/lazer`）在曲库快照里找标题、艺术家、作者相同、难度名以本工程难度名开头的谱，MD5 与某一版的文件相同就是「和第 n 版一样」，不同就是「在 lazer 里改过」，可「读回」（`op=readback`，按 MD5 找文件）：成为新一版，改动小节记成手改；timing 不同时只取音符、照工程的 timing。读不了曲库时列表为空并给出原因，不报错。

## 后果

- 范围不是保证：模型写不出的技法加不出来，界面与日志都直说。八池互相牵连（加 Jack 常带着加 Stamina），范围给得太窄或互相矛盾时会一直达不到。
- 候选文件只在试听期间存在；工程文件多了一个 `candidates` 字段（旧工程读进来是空列表）。
- 编辑器的绘制代码是回放查看器的精简版，没有抽成共用文件：回放查看器是写到磁盘上、可以直接用 file:// 打开的独立页面，不能引用看板的脚本。
- 工程文件多了 `hand_bars`（旧工程读进来是空列表）。
- 页内撤销只在页面里：刷新或换项目就没了，保存过的版本仍可用上一版/下一版退回。
- 测试：`tests/test_generator_project.py`（按小节重写、锁定段拒绝、试听/采用/放弃、换版本后候选作废、编辑器数据、手改保存与拒绝、手改小节拒绝重写、解锁放开、锚定解开、实时读数、拆开/合并/挪边界、打开任意谱与拒绝 4K）、`tests/test_generator_mix.py`（范围的写法、打分、降难权重、按范围挑候选）、`tests/test_dashboard.py`（编辑器 API、只开工程文件、试听与采用、`editor_rate`、手改保存、段落操作、没有 lazer 时的读回列表、`editor_open`）。
