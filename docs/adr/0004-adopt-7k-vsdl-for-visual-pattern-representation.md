# 0004. 确立 7k 视觉键形标准描述语言 (7k-VSDL) 作为铺面客观几何表征公理

为了实现铺面固有难度第一性原理评价并彻底摆脱经验主义黑话的污染，我们确立 **7k 视觉键形标准描述语言 (7k-VSDL)** 作为全项目解析、切片与特征建模的唯一权威空间与时序表征规范。

## 决策背景

社区既有术语（如 Jack、Stream、Chordjack、Tech、Shield、Inverse）定义边界模糊、交叉重叠严重，且充满先验技法偏见。传统官方星级算法因依赖单轨简单时间差（Delta-Time）模型，在处理 7K 空间稀释、多押内部肌群张力、双手解耦与长条反相位时产生严重失真（如将 10+★ 极端神图虚标为 7.79★）。我们需要一套完全基于客观空间拓扑、物理状态闭集与可计算组合代数的形式化表征公理。

## 方案取舍

- **被拒绝的方案 1（纯程序化 AST/JSON）**：缺乏下落式空间直观性，人机交互与视觉校验成本极高。
- **被拒绝的方案 2（传统 BBS 字符流）**：缺乏结构化属性元数据，无法表达双手解耦与长条释放对偶。
- **被拒绝的方案 3（全局标量跨度 `@span=N`）**：无法区分多押内部抠空（如 `L{3,1}[gap:1]` 开指）与相邻并指（`R{2,3}[adj]`）的真实生理肌群负荷。
- **采纳的方案（7k-VSDL）**：
  1. 底层绝对索引 `1..7` 与高层双向对称 `[L3 L2 L1 | S | R1 R2 R3]` 双射映射；
  2. 自底向上（`↑ time`）所见即所得下落式矩阵，严格对齐判定线视觉；
  3. 6 元图元状态闭集（`.`、`o`、`⎵`、`|`、`⎴`、`x`），将持续保持与抬手释放彻底解耦；
  4. 三区手型拓扑签名（`L{..}[gap/adj] | S | R{..}[gap/adj]`）；
  5. 微观原子切片（0.5~2 拍动态连贯窗口 + 4 轴客观几何张量）；
  6. 宏观长切片组合代数（串联 `->` 与空间解耦并联 `||`）。

## 架构影响

1. **统一 DSL 与切片渲染**：切片工具链 CLI 与未来的 Web 分析器直接生成并支持 7k-VSDL 格式输出与反向解析。
2. **特征工程与难度建模底座**：后续所有技法维度的自然涌现（Jinjin Dan 拆解与盲测）均建立在 7k-VSDL 提取的客观几何张量之上，杜绝人工主观打标。
