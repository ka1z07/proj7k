# 0005. 确立人类玩家直觉分析框架与案例审问逆向归纳 SOP

我们将人类玩家对 7K 铺面的第一直觉（手感、视认卡顿、发力阻力、容易暴毙）严格基于认知心理学与运动生物力学建立四维客观阻力模型，并确立标准六步审问与逆向归纳 SOP。

## 决策背景

在以往讨论与既有算法中，“为什么这张图难、容易在哪里断连”往往被归为资深玩家不可言说的内隐经验与感性描述，导致学术解构与算法建模缺乏物理抓手。特别是针对标准 7K 指法（L3/R3 无名指、L2/R2 中指、L1/R1 食指、S 大拇指），无名指与中指的解剖学肌腱深度耦合（Juncturae Tendinum）在 `[gap:1]`（抠空中指）时产生的生理拉扯，以及高密 LN 中由背景压满导致的“图-底反转”负空间知觉倒错，此前从未被形式化归因。

## 方案取舍

- **被拒绝的方案 1（纯黑盒感性打标）**：仅由高水平玩家口头评述“此段难受/容易暴毙”，无法跨图泛化或被计算机程序复刻。
- **被拒绝的方案 2（简单统计物理量叠加）**：仅统计 NPS、总物量与平均密度，完全忽略了人类眼球中央凹视野限制、前臂无氧糖酵解耐力阈值与长条释放级联容灾机制。
- **采纳的方案（四维直觉框架 + 六步标准 SOP）**：
  1. **视觉知觉阻力**：空间组块分治、负空间图-底反转、密度突变预测迟滞；
  2. **生物力学负荷**：标准无名指/中指腱鞘耦合、自由度锁定运动压制（Enslaving Effect）、腕部与前臂乳酸衰减；
  3. **容错瓶颈**：长条尾判早放级联崩溃（Release Cascade）、空间邻轨漂移；
  4. **复合非线性畸变**：单项技法叠加时的非线性难度乘性膨胀。
  5. **标准化六步 SOP**：全景扫描 $\to$ VSDL 标注 $\to$ 原子切分 $\to$ 宏观合成 $\to$ 四维审问 $\to$ Jinjin Dan 对齐。

## 架构影响

1. **统一审问语言**：后续所有针对 Jinjin Dan 标杆曲目与实战铺面的个案解剖均必须产出符合规范的归纳卡片（Induction Card）。
2. **分析工具链集成**：`proj7k.analyzer` 直接提供平均锁指、手型张力比率与反相位对偶率等物理直觉量化数据。
3. **为盲测验证铺平道路**：为后续 Issue #7（方法论终稿与盲测一致性验证）提供了可证伪的直觉检验量表。
