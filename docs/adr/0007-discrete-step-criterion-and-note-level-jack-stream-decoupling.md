# 离散步距判据与音符级叠切正交解耦模型

- **状态**：accepted
- **日期**：2026-09-16
- **背景**：针对 om7k 铺面中多押弦叠（Chordjack，如 Jinjin 10th Dan SAMBAJACK）因多押产生极高瞬时 NPS 而被传统宏观密度算法严重误判为切键（Stream）的系统性缺陷，以及滚奏被纯绝对时间窗口误判为叠键的问题。

## 决策内容

1. **离散步距判据 (Discrete Step-Distance Criterion, $\Delta k = 1$)**：
   将全谱音符按时序聚合为离散和弦步（Chord Steps $S_0, S_1, \dots, S_m$，和弦内聚时间容差 $\epsilon_{\text{chord}} = 8.0\text{ms}$）。同轨音符仅在紧邻节拍步（$\Delta k = 1$）且时差满足 $\Delta t \le T_{\text{jack}} = 220.0\text{ms}$ 时，判定为原位停滞叠键；若两击跨越其他节拍步（$\Delta k \ge 2$），则严格判定为流式切键。

2. **音符级正交语义切分 (Note-Level Semantic Partitioning)**：
   全谱每个具体音符严格归类为 **Jack Note** 或 **Flow Note**。连叠的首击音符（$S_{k-1}$）作为空间流式切入键（Root as Flow/Trigger），后续同轨复击音符（$S_k$）归为 Jack Note，实现生物力学回弹阻抗的微观守恒与多押和弦内部不同轨道的异构解耦。

3. **物理负载与耐力饱和算子**：
   - **弦叠多押抓握负荷**：$C_{\text{chord}} = 1.0 + 0.35 \cdot (N_{\text{chord}} - 1)$，量化手掌维持固定多指抓握姿态下的整体腕臂震颤阻抗；
   - **长连叠双曲正切饱和**：$W(L) = 1.0 + 1.5 \cdot \tanh((L - 2) / 3.0)$，在 5~7 连叠后平滑达到约 2.5 倍最大耐力疲劳平台，防止超长叠星级发散；
   - **有效流式通量 (Flow NPS)**：Stream 雷达仅由流式音符通量驱动，彻底消除高密多押弦叠对切键指标的虚假污染。

4. **切键排布拓扑确界与 Bracket 保守调制**：
   - **排布难度确界**：以严格双手交替切键（Interlocking Bimanual Stream，单手动作时钟减半，零手内拮抗）为同等密度下切键难度的**客观下限**；以同手括号混切（Intra-Hand Bracket Stream，在微观时钟下单手于外侧双押与中间单押之间反相震荡，诱发严重腱间绞杀）为**客观上限**。
   - **核心物理量**：引入单手动作时钟压缩比 $\kappa_{\text{clock}} = \Delta t_{\text{global}} / \Delta t_{\text{hand}}$ 与基于 7k-VSDL 的括号拓扑相变频率 $\rho_{\text{bracket}}$。
   - **保守标定原则**：初始实现对 Bracket 的加成倍率采取保守设计（如初始温和加成 $\beta_{\text{bracket}} \approx 0.40$），先确立结构与数据契约，后续结合全量跑批实证与段位单调性再微调具体参数。

## 权衡与取舍 (Considered Options & Trade-offs)

- **放弃纯绝对时间窗口判据 ($\Delta t < 160\text{ms}$)**：绝对时间无法区分“手指留在原位无法回弹的停滞”与“跨轨空间位移交替回弹的滚奏”，无法解决 4 轨高速滚奏误判为叠键以及 136~160 BPM 弦叠漏判问题。
- **放弃整链双向全标叠键**：起手键在生理击键动力学上与普通单音无异，将起手键归为流式音符更贴近肌肉回弹本质，且天然保证全谱音符通量的代数闭环。
- **放弃孤立指距跨度（Gap:1）加权**：对于成熟 7K 竞技玩家，纯物理跨度在流式切键中的边际难度增量基本为 0；难度的真实断层完全来自于双手分担 vs 单手全频承压，以及同手手型的 Bracket 反相撕扯。
