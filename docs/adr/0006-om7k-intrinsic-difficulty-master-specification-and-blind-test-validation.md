# 0006. 确立《om7k 铺面固有难度评价与技法解构方法论规范》并完成视角复刻盲测验证

我们将前序关于固有难度第一性原理、Jinjin Dan 权威基准、7k-VSDL 视觉语言、人类直觉分析框架与六步审问 SOP 的所有方法论成果正式整合沉淀为系统的《om7k 铺面固有难度评价与技法解构方法论规范》，确立反键难度 BPM 时钟缩放律，并通过三维视角复刻盲测验证其与人类资深玩家直觉的完全同构性。

## 决策背景

在完成 Issue #3 至 #6 的各专项探索后，proj7k 已经具备了完整的微观图元闭集、手型拓扑签名、四维直觉阻力模型及配套的切片/分析工具链。然而，若缺乏一份具有宪章地位的系统级规范文档，后续规模化经验蒸馏与算法引擎落地将面临口径不一、概念分散的风险。此外，面对反键（LN Inverse）等具有强烈认知门槛欺骗性的特殊技法，若脱离动作时钟窗口（$\Delta t$）与 BPM 盲目评估锁指数，极易产生将 140 BPM 低速反键过度高估为 9★~10★ 的严重偏差（人类高水平玩家明确指出：低速反键铺面其实际难度上限通常仅在 5★ 左右，只有在更高 BPM 下维持同样高锁指密度，动作容错窗口被压缩至极限时才会跃升为真正高难）。因此，必须对反键评判标准进行严密校准，并通过盲测验证方法论的客观有效性。

## 方案取舍

- **被拒绝的方案 1（保留碎片化子规范）**：仅依靠独立的 ADR 与零散文档指导开发，缺乏全局公理化架构与统一打分量规。
- **被拒绝的方案 2（静态物理量单因子评级）**：仅根据持键率（Hold%）或平均锁指数直接线性推导难度，忽视了动作时钟窗口（$\Delta t$）对反键难度的非线性控制作用。
- **采纳的方案（统一方法论主规范 + 反键 BPM 缩放律 + 三维盲测验证协议）**：
  1. **整合沉淀 Master Specification**：在 `docs/methodology/om7k-intrinsic-difficulty-specification.md` 中公理化统合第一性原理、7K 解剖学坐标系、7k-VSDL、4 维直觉模型、6 步 SOP 与盲测准则；
  2. **确立反键 BPM 缩放律 (Inverse BPM Scaling Law)**：低速反键（$\le 145$ BPM）受认知门槛影响，实际固有难度上限仅约 5★；只有在更高 BPM（$\ge 180 \sim 200+$ BPM）下维持同样高锁指密度，难度才会跃升为 9★ ~ 10★+ 极限高难；
  3. **视角复刻盲测验证**：对未曾接触的 3 个代表性用例（Regular Stream 8th Dan、LN Inverse 7th Dan、LN Release 7th Dan）实施严格信息遮蔽盲测，在审题视角对齐度（35%）、难点归因一致率（35%）与段位锚定命中率（30%）三大维度上取得 99.3 分均分，实现 0 段位偏差精准对齐。

## 修订 1：反键门槛与动作时钟改读归一化 BPM\*（2026-09-22，工单 #51）

**修订内容。** 决策 2 的 `145` / `180` 两个门槛，与架构影响第 2 条那个 $\text{BPM} \times \Delta t_{\text{action}}$ 非线性缩放门控的输入，由谱面的**标注 BPM** 改为 `parser.notation_normalized_bpm` 给出的 **BPM\***：

$$\text{BPM}^* = \frac{60000}{4 \times \operatorname{median}(\Delta t)} = \frac{\text{BPM}_{\text{annotated}}}{4 \times \text{note\_value}}, \qquad \text{note\_value} = \frac{\operatorname{median}(\Delta t)}{\text{beat\_length}}$$

门槛数值本身不变。

**理由。** 标注 BPM 的记谱刻度并不统一。实测 120 张标杆谱，「中位音节距 ÷ 记谱拍长」的取值从 1/12 拍跨到 1/1 拍共 12 倍：写成 1/16 的 71 张、1/8 的 28 张、整拍的 4 张，另有 11 张写得比实际更细。而 `compute_action_window(bpm, 4)` 是「该 BPM 下的十六分音符」，于是它把每一张谱都当成 1/16 记谱——对写得粗的谱，动作时钟比真实击键间隔小最多 4 倍，那一对门槛也就落在错误的操作点上。LN Inverse 的 15 级阶梯是这个缺陷的完整标本：0th–7th 写成 1/8 或整拍、8th–Stellium 写成 1/16，标注 BPM 看似单调（90→240）有一半是中途换挡换出来的。

BPM\* 的定义等价于「把该谱的中位音节距读作十六分音符」，因此**同一物理谱面的两种记谱归一化到同一个数**——这正是本修订要的不变性。它使 $\Delta t_{\text{action}}$ 等于该谱真实的音节距。

**代价与边界。** **BPM\* 不是音乐速度，是击键间距在一个固定约定下的数值。** 门槛因此读的是间距而不是曲速：写成整拍的谱因子 0.25（LN Inverse 3rd 200 → 48.5、LN Release 4th 118 → 29.5），落入低速认知门槛档并吃 5★ 帽；写成 1/8 的因子 0.50。这是本修订有意接受的语义转移——决策 2 那句「维持同样高锁指密度」本来就关于间距，「低速反键」在新刻度上读作「稀疏反键」。全库影响：58/120 张星级移动，全部落在四条 LN 梯队（Regular 四条几乎不动，因为 `locked_fingers = 0` 时 BPM 在该路径上不生效），移动者平均 0.10★、最大 1.43★；四档锚点带与 15 级单调性均通过。

约定常数 `DEFAULT_DIVISOR` 同时决定门槛的量纲，改它等于改标定，已在方法学指纹覆盖范围内。

**同时失去的东西。** `tests/test_batch.py` 原本用「标注 130 BPM 高锁指 vs 标注 220 BPM 中锁指」证明伪倒挂已被消除；在新刻度上两张合成谱都落进低速档，该断言不再有判别力，其夹具按新语义重建。

**未修订、但已知的边界。** 门槛的**数值** 145 / 180 仍是旧刻度上标定的产物，本修订只改了它们被求值的刻度，没有重新推导。重新推导属于驱动票——那张票才有「反键在本维梯队上达标」的验收压力。
