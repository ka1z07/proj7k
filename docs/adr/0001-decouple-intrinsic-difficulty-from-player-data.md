# 0001. 铺面固有难度评价与玩家游玩表现数据彻底解耦

评判 om7k 铺面的难度绝对不能与任何玩家游玩表现数据（如 pp、得分率、通过率、天梯排行榜）挂钩。铺面难度被严格定义为由其物理键形排列、时序机制与认知负荷所决定的“固有属性”（Intrinsic Difficulty）。

## 决策背景

官方 Star Rating (SR) 底层逻辑无法表现 7k 铺面的多维复杂度，且 Performance Points (pp) 是基于失衡 SR 计算出的虚高指标。玩家群体在技法偏好、擅长领域及各 VSRG 习惯上存在巨大异质性，任何基于玩家打图数据反推铺面难度的方法都会导致难度体系产生群体性偏置与严重失衡。

## 方案取舍

- **被拒绝的方案**：基于玩家通过率或准确率统计回归难度（如 Elo 评级、pp 反算、社群打分加权）。
- **采纳的方案**：将铺面难度完全作为白盒物理固有属性，从谱面本身的键形几何、时序时钟、手指协调负荷等物理与认知特征进行纯客观解构。

## 架构影响

玩家游玩数据（`.osr` 回放、准确率、判定时序）在系统中被严格隔离于“玩家能力画像与缺陷诊断”链路，仅用于为玩家自身提供训练反馈，绝不反向污染或参与铺面固有难度的计算。
