# 0028. 画像水平：跨局拟合，不取单局最高

- **状态**：accepted（2026-10-12；修订 ADR-0020 决策 2 的汇总一侧，取代 ADR-0022 决策 2 的玩家侧 p 范数；引擎未动）。
- **背景**：Kai 反馈玩家画像「整体都偏高」（PR #73 修完 mod 之后）。用他库里 470 局有效对局复核，有三个独立的高估来源：
  1. **跨局取最高。** 每项技法取窗口内所有对局里最高的单局读数。单局读数本身有噪声，局数一多，最高值就是一个极端顺序统计量：八项技法的最高值在 9.0–9.6★，中位数只有 6.3–6.9★。
  2. **单局外推太陡。** 单局读数是把引擎方程反过来解（ADR-0020 决策 2），曲线的陡度是引擎的 `beta = 6`。真实玩家的准度损失随难度上升要慢得多：把 Kai 每局的（ln D_k，准度损失率）放在一起拟合，斜率只有 1.3–3.9。准度会饱和，打不过的谱也还有 86–90%。所以难谱上的单局也被反推成高水平。
  3. **总评的 p 范数。** `player_overall_star` 把八项技法星级用 p = 4、阻尼 0.08 合成，八项相等时结果是单项的 1.31 倍。拿谱面自己的八项技法星级去合成，结果比引擎给这张谱的总星级平均高 1.8★（中位 +1.79，p10 +1.21，p90 +2.49）。谱面总星级约等于最强技法（中位差 −0.07），玩家总评却被抬到所有单项之上。Kai 的全历史总评因此是 12.6★（Stellium）。

## 决策内容

1. **技法水平 := 跨局拟合的 ε 点。** 对窗口内测到该技法的每局，取（谱面的 D_k，该技法隶属加权的事件数 W，准度损失 L），用 logistic 拟合损失率 L/W 对 ln D_k 的关系（每局权重 √W），水平取拟合损失率恰为 ε_k 的 D。这保留 ADR-0020 的锚点「丢失率恰为容差的玩家，水平等于谱面的 D」，但曲线的陡度从玩家自己的数据来，不借引擎的 β。结果限制在所玩谱面的 D 范围内，不往最难谱之外外推。
2. **局数不够或斜率不为正时取中位数。** 少于 `MIN_FIT_PLAYS = 5` 局，或拟合出「越难丢得越少」，就取各局单局读数的中位数，不取最高。
3. **总评 := 同一个拟合，用在谱面总难度上。** 每局再记一份「总体」读数：用全部已打事件、按谱面总难度的容差 `eps_total`（§3.3）反解引擎的总方程（单局雷达的段位也由它给出）。跨局时用决策 1 的拟合，ε 取各局 `eps_total` 的均值。没有这份读数的快照（手工构造的、旧版本写的）退回到最强单项，不再做 p 范数合成。`player_overall_star` 与两个常数删除。
4. **暴毙下界不变。** 失败局致死前一秒的需求读数仍是该技法水平的下界（ADR-0012，ADR-0020 决策 3），只在它高于决策 1、2 的结果时生效。
5. **快照多记三样，旧快照重读。** 每项技法加 `events`、`lost`，`summary.overall` 记总体读数；`SNAPSHOT_INGEST_VERSION = 3`。「导入回放」会重读版本更低的快照；没重读之前，它们只能走决策 2 的中位数路径。

## 后果

- Kai 的画像（全部 470 局）：总评从 12.6★ 降到 6.7★（7th），八项技法从 9.0–9.6★ 降到 6.0–7.2★。他 96% 准度对应的谱面总星级大约是 6.9★，与新总评一致。
- 「近期 vs 全历史」对比现在比的是两个窗口的拟合水平，不再是两个窗口的最高单局。
- 单局雷达（回放诊断页）的八项读数不变，只有总评与段位改由决策 3 给出。
- 引擎、星级指纹、段位表都没动；两道闸门不受影响。
