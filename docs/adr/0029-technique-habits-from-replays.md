# 0029. 发力习惯：从回放的按键时序跨局读出

- **状态**：accepted（2026-10-14；新增 `profiler/habits.py`，不动引擎、不动画像水平的拟合）。
- **背景**：Kai 问能不能从回放推出玩家的发力技巧和习惯。lazer 回放每一帧是「时间增量 + 7 列按键位掩码」，实测 817 万帧的时间全是整数毫秒，按键状态一变就记一帧。所以回放给的是每个键按下、松开的时刻（约 1ms 精度，同一毫秒内的先后分不出），没有手指、力度、键盘行程。在 Kai 的 470 局上的验证（见「后果」）显示，这些时序足以稳定读出手的分工和一批按键习惯。现有 `pathology.py`（ADR-0012）是单局的，没用到米键的松键时刻和和弦内部的先后。

## 决策内容

1. **每局记可加的统计量，跨局相加。** 摄入时（`run_ingestion`）从对齐结果和原始帧算一份 `HabitStats`，存进快照 `summary.habits`：每列的偏移和与平方和、米键按住时长直方图（4ms 一格）、LN 尾判偏移与早松/晚松计数、空按数；每对列在和弦里的偏移和、平方和、交叉积（算相关）、谁先按的计数、按下时间差直方图（1ms 一格）；按同列间隔分段的按住时长直方图；同手换键时前键未松的计数；同列叠键两下的偏移和。全部是和与直方图，所以跨局合并就是相加，分位数从合并后的直方图读。
2. **时间一律换算成真实时间。** 歌曲时间的偏移、按住时长都除以速率，变速局和 1.0x 局可比。Mirror 局在翻转后的列空间对齐，所以列就是玩家的物理按键。
3. **中键归哪只手，用和弦误差相关性判断。** 一只手的几个键一起动，和弦里它们的时间误差相关性高于跨手。左三列、右三列固定；中键与右手三列的平均相关比与左手高出 `MIDDLE_HAND_MARGIN = 0.03`、且按下时间差不更大，就判右手，反之判左手。两只手在时序上本身分不开（同手平均相关不比跨手高出这个余量）时，不判。少于 `MIN_PAIR_CHORDS = 30` 个和弦的列对不参与。
4. **只报时序能证明的东西。** 不推断具体手指、不判断手腕叠还是手指叠、不读力度。页面明说中键归属是推断。按住时长也受键盘触发设置（如 Rapid Trigger）影响，和手的习惯分不开。
5. **快照版本升到 4。** `SNAPSHOT_INGEST_VERSION = 4`；「导入回放」会重读旧快照补上 `summary.habits`。没补之前它们不进习惯统计，页面显示有几局缺数据。

## 后果

- 控制台「回放与画像」多一个「发力习惯」页（`profile_habits` 任务）；命令行 `python3 -m proj7k.profiler --player <名字> --habits [--all-time] [--json]`。
- Kai 的 470 局：中键判为右手（与右手相关 0.33、与左手 0.19；按下时间差 11ms 对 17ms），左手和弦外侧先按（L3 先按 78%），米键按住约 90ms 且不随间隔变长，滚奏阈值约 112ms，80ms 左右的叠键第一下早 12ms、第二下晚 23ms。
- 每局快照的 summary 多约 12KB。
- 引擎、星级指纹、段位表都没动；两道闸门不受影响。
- 目前只有 Kai 一个人的数据，结果是相对他自己的；要和别人比需要别的玩家的回放做基线。
