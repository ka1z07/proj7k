# 0036. 桌面端外壳改成侧栏，主页围绕「当前水平 + 下一步」

- **状态**：accepted（2026-10-21；修订 ADR-0034 的外壳与主页布局）。
- **背景**：Kai 要改善桌面端设计。在云端用标杆谱面造的假曲库跑了一遍、逐页截图，主要问题是：顶栏 8 个同级页签把玩家页和工具页混在一起，右上角堆满数据库状态、重启 osu!、连接状态与语言按钮，窗口窄到 1000px 就折成两行；主页约 2400px 长、十几个同样大小的数字框，最重要的「当前水平」只是角落里的小字；配色是青色标题加紫色渐变按钮两套强调色，每块都套带阴影的卡片。Kai 选了先改「整体框架 + 主页」。

## 决策内容

1. **左侧栏导航**（`shell.html`）：分「玩家」（主页 / 游玩记录 / 曲库）、「工具」（实时雷达 / 回放与画像 / 降阶练习 / 谱面生成）、「设置」（曲库同步）三组，每项一个内联 SVG 图标。窗口窄于 1080px 时只留图标，名字放在悬停提示里。页面本身仍是各自的 iframe，切换逻辑不变。
2. **状态收进侧栏底部一块**：osu!lazer 状态（圆点：绿 = 运行中，黄 = 没找到数据库）、游戏里当前选中的谱（点击打开谱面详情）、正在跑的任务、「重启 osu!」；下面一行是和看板的连接与语言切换。玩家选择框（有多位玩家时）也在这里。
3. **一套视觉**（`app.css`）：底色 → 侧栏 → 卡片 → 凸起四级表面；唯一的强调色是粉色 `--accent`（当前页、主按钮、选中项、单选/复选框），蓝色只用于数据（曲线的点、技法条、活跃度）。卡片去掉投影，标题改成正文色。所有页面共用这份样式，所以工具页跟着换了外观，结构没动。
4. **主页**：
   - 头部右侧是大字的当前水平：有回放画像时用画像的总实力，否则用最难 10 次通关的中位数估算（至少 3 次通关；`overview()["level"]` 带 `source` 区分）。
   - 一行 6 个数字：游玩次数、时长、近 30 天准确率 / 常打星级 / 通关最高（各带与前 30 天的差）、评级。原来的「总览」与「最近 30 天」两块合并进来。
   - 左栏：进步曲线（点变小变淡，近 15 局中位数改用强调色画在点上面）、最近游玩、最难的通关；右栏：「下一步练什么」、八项技法、段位进度（15 格，标出当前段位，点进曲库）、活跃度。
   - 「下一步练什么」（`overview()["next"]`）：补短板（画像的最弱技法，跳到出练习）；差一点的谱（90 天内打过、星级在水平 −0.75～+0.5★、最好成绩还没到 A，最多 4 张）；冲下一段（曲库里该段有几张、通关几张、几张没打过，可跳曲库或谱面生成并预选该段位）。没有画像时第一条换成「先导入回放」。

## 后果

- 新文字照 ADR-0035 都有英文对照。
- 实时雷达页（`live/static/index.html`）仍是自己的一套英文风格、自带标题栏；它也是 OBS 叠加层，留待单独统一。
- 工具页只换了外观，仍是一次铺开的表单；「从曲库选谱、高级选项折叠」是下一步。
