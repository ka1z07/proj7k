## 0. 摘要

现行引擎有两个互不为函数的难度原语：**驱动**（8 个整谱标量，量纲各异，经 8 套锚定律换成星）与**应变**（一条时间序列，只能给总量）。技法语义住在前者，难度量纲住在后者，所以它们必然打架。本方案只留一个原语：

1. **一个量**。每个动作（一次按下或一次释放）得到一个**应变** $\sigma_i$：物理代价（手钟、指钟、锁指对时钟的压缩、释放辨识）经认知调制，沿「手指 → 手」两级效应器做衰减累积。全引擎只有这一个场，单位统一。
2. **一个汇聚算子**。总难度 $T = (\sum_i \sigma_i^p)^{1/p}$。它是「理想玩家的期望失误数等于预算」这条方程的解，不需要时间窗、分位数或 BPM。
3. **技法是同一个场上的记账，不是另一套公式**。每个动作按它所属的**排列类**把自己的代价记到技法名下；重叠的动作拆账，不重复记。技法难度 $D_k$ 用同一个算子在自己那份上读出。于是恒有 $\sum_k D_k^p = T^p$，主导技法就是 $\arg\max_k D_k$——只有一种读法。
4. **一把尺**。$T$ 与 8 个 $D_k$ 过**同一条**两参数单调映射变成星。官方 SR 只以 30 个「（轨，段位）中位数」的粒度出现在标定里——那是刻度；120 个逐谱数值**不进入损失**，只作诊断。

原型实测（120 谱，粗标定；「现行引擎」是今天在同一批谱上按同一口径复测的 HEAD）：

| 读数 | 现行引擎 | 原型 |
| :--- | ---: | ---: |
| 8 条本维阶梯上的技法难度：平均 Kendall τ | 0.880 | 0.964 |
| 同上：相邻倒挂（共 112 对） | 26 | 12 |
| 主导技法 = 本池技法 | 80（分值口径）/ 89（驱动口径）；两种口径只在 66/120 一致 | 72（单一口径） |
| 总星级对官方 SR（诊断，未拟合）：MAE / Spearman ρ | 0.840 / 0.931 | 0.462 / 0.986 |
| 能移动星级的常数 | 174 个登记项 + 16 个锚 | 17 + 2 |

你预判的缺陷（子集越大越容易主导）在原型里被完整复现：全权重重叠子集口径下主导命中 50/120，其中三条专项 LN 阶梯的 45 张谱有 43 张被 LN General 拿走。第 3 条的拆账规则把它修到 72/120；剩下没命中的主要不是这个缺陷，见 §5.3。

**没有做到的**，先说在前面：

- **严格单调没有达成**。原型剩 12 处相邻倒挂，逐条列在 §9.3；其中 9 处落在官方 SR 自己也倒挂或打平的段位对上。
- **LN 侧的专项物理没有立住**。粗搜把锁指压缩与释放辨识两项压到接近 0（§9.6）：原型里 LN 的难度基本就是「按下 + 释放」的动作密度。后果是 LN Release 与 LN Tech 在自己池里的主导命中都是 0/15，K5 的合成拉伸测试按字面读没有通过（§9.5）。这是本方案最大的未解问题，§10 Q6、Q8。
- **主导命中没有超过现行引擎**。72/120 低于现行的分值口径（80）与驱动口径（89）。差距全在 LN Tech 与 LN Release 两个池（原型 0/30）；另外六个池上原型是 72/90，现行引擎的两种口径是 58/90 与 74/90。
- **星尺的底端没有地板**。极稀疏的谱读到 0★ 以下（LN Release 0th 读 −0.24★，官方 1.63）。§10 Q7。
- **常数还不能当真**。6 组种子的读数稳定，常数不稳定（§9.6）：结构站得住，数值是粗搜的产物。

## 2. 诊断：双系统为什么必然矛盾

- **驱动是整谱统计量**。它对时间是盲的（#56：314 秒的均匀高密谱被读成 8th，而它的 P90 应变落在 10th–Gamma）。8 个驱动量纲各异，所以需要 8 套锚定律，指数从 0.093 到 0.879 相差近十倍，同一段位在不同轴上读数不等价（ADR-0016 裁定 4）。
- **应变是时间序列**。它对技法是盲的，只能给总量；ADR-0016 之后它只剩 fallback。
- **两者互不为函数**。原型提交 `671b9a1` 实测：只改列不改时间，特征向量平均移动 0.76%，星级移动 3.67★；`jackify` 变体让 P90 应变 +414.7%，合成星级 +0.00★。
- **技法难度自己的阶梯并不单调**。今天复测：8 个技法分值在各自池内的平均 τ 是 0.880、相邻倒挂 26 处；被闸门守住的 0.9255 / 22 是**总星级**的读数。交付物 2 要的那件事，现行架构没有在量。
- **主导技法有两种读法**（驱动 argmax 与分值 argmax），只在 66/120 张谱上一致。

根因是：**技法语义与难度量纲被放在了两个原语上**。调和它们的每一步（载体、Rule C/D/E、逐轴锚、软门）都在给接缝打补丁。本方案只留一个原语，让技法成为它的一个视图。

```
.osu

  ▼
动作流          每个音符 → 一次按下；每条长条再加一次释放。同刻动作归为一步
  │
  ▼
时钟与状态      指钟 w（同指上次可起动 → 现在）   手钟 Δ（同手上一步 → 现在）
                锁指数 held（此刻被长条锁住的其他手指）   异长共持数 ñ
                语境：多押语境 χ、LN 语境 q、节奏不可预测度 C
  │
  ▼
动作代价        按下：基础 + 手钟项 h(Δ/φ) + 指钟项 j(w/φ)      φ = 锁指对时钟的压缩
                释放：基础 r₀ + 辨识 r₁·ñ
                × 认知调制 (1 + α·C)
  │
  ├─ 归属表：按排列类把每个动作的代价记到技法名下（重叠则拆账，合计恰为该动作的代价）
  ▼
效应器累积      指级 F_f（τ_F）与手级 H_h（τ_H），指数衰减。线性，所以记账穿过累积后仍然守恒
  │
  ▼
逐动作应变      σ_i = Σ_k σ_{i,k}              ← 全引擎唯一的难度原语
  │
  ├── 总难度    T   = (Σ_i σ_i^p)^{1/p}
  ├── 技法难度  D_k = (Σ_i σ_{i,k}·σ_i^{p-1})^{1/p}        恒等式：Σ_k D_k^p = T^p
  └── 主导技法  argmax_k D_k；份额 s_k = (D_k/T)^p，Σ s_k = 1
  │
  ▼
星尺            ★ = a·ln(·) + b                T 与 8 个 D_k 共用同一条映射
```

三处与现行架构的本质差别：

- **没有整谱特征**。`avg_nps`、`peak_4m_nps`、`hold_ratio`、`mean_locked_fingers` 这类量在引擎里不存在；密度不是输入，是累积的结果。
- **没有逐技法公式**。8 个技法共用 $\sigma_i$，差别只在归属表的一行。
- **没有逐技法刻度**。只有一条映射，跨技法可比是构造出来的，不是拟合出来的。

## 4. 模型

### 4.1 动作与效应器

- **动作** $a_i = (t_i, f_i, \kappa_i)$：时刻、手指、种类 $\kappa \in \{\downarrow, \uparrow\}$。米键与长条头是 $\downarrow$，长条尾是 $\uparrow$。时刻相差 ≤ 8 ms 的动作归为同一**步**（沿用 ADR-0007 的和弦内聚容差）。
- **效应器**：7 根手指，2 只手。`L3 L2 L1` 属左手，`R1 R2 R3` 属右手。拇指 `S` 以 1/2 权重同时计入两只手——这是保持镜像不变的中性取法，是否改成「拇指归属一只手」见 §10 Q4。
- **状态**：$\text{held}_s(i)$、$\text{held}_o(i)$ 是动作 $i$ 发生时同手、异手正被长条锁住的其他手指数（恰在此刻起止的不计）。

### 4.2 时钟

所有时间压力都来自两个时钟，单位毫秒：

- **指钟** $w_i$（仅按下）：这根手指从「可以再次起动」到现在的间隔。同轨上一个物件是米键，取它的按下时刻；是长条，取它的释放时刻**再加释放宽限** $\eta$（K11：长条尾可以早放，所以长条之后手指的可用时间比记谱的尾→头间隔宽）。
- **手钟** $\Delta_i$：同手上一步到现在的间隔。若这根手指就在同手的上一步里（原位复击），手钟项记 0——那是指钟的事，不重复计费。释放动作的手钟取同手上一个动作（按或放）。拇指不参与手内换指，原型里它没有手钟项，只有基础项与指钟项（§10 Q4）。

K2 不需要专门的算子：严格双手交替时每只手的手钟是全谱步距的两倍，同手全频时等于全谱步距（原型实测见 §9.5）。

### 4.3 物理代价

按下：

$$c_i^{\downarrow} = \underbrace{b\,(1 + g\,(n_i - 1))}_{\text{基础动作}} + \underbrace{h(\Delta_i / \varphi_i)}_{\text{手钟：手内换指}} + \underbrace{j(w_i / \varphi_i)}_{\text{指钟：同指复击}}$$

$$h(\Delta) = K_H\,\Delta^{-a_H}, \qquad j(w) = K_J\,w^{-a_J}, \qquad \varphi_i = 1 + \lambda_s\,\text{held}_s(i) + \lambda_o\,\text{held}_o(i)$$

- $b = 1$ 定单位；$n_i$ 是同手同步的按键数，$g$ 是多押耦合。
- 两个时钟项都是**无尺度幂律**，没有阈值、没有分段。
- **没有手型跨度项**（K3）。`[gap:1]` 之类的静态手型不计费；单手全频与手内反相的代价由手钟与隔步复击的指钟给出。
- **锁指不是乘子，是时钟压缩**（K9）。被锁的手指降低余指的频率上限，等价于余指可用的时间被压缩 $\varphi$ 倍。设计意图是让 K5 从这里长出来：锁指的代价挂在时钟项上，慢谱的时钟项本来就小，压缩它几乎不加分；快谱才被放大——现行引擎靠 `BPM* ≤ 145` 的分段门槛做的事，在这里是连续的。**这条通道在原型里没有立住**：粗搜把 $\lambda_s$ 压到 0.1 左右，K5 目前主要靠「慢谱本来就稀」成立，见 §9.5 与 §10 Q8。

释放：

$$c_i^{\uparrow} = \big(r_0 + r_1\,\tilde n_i\big)\,\big(1 + h(\Delta_i)\big), \qquad \tilde n_i = n^{\text{diff}}_s(i) + \kappa\, n^{\text{diff}}_o(i)$$

- $r_0$ 是「定时抬手」本身；$r_1 \tilde n_i$ 是**松放辨识**：抬手瞬间仍被持有、且**长度与本条不同**的长条数（同手计 1，异手计 $\kappa$）。这是 ADR-0015 落定的 `release_lock_depth` 语义，从整谱平均变成了逐动作量。等长谱上 $\tilde n_i \equiv 0$，K6 按构造精确成立。

### 4.4 认知调制

你给的方向是「认知因读谱、排列与节奏而影响执行」。本设计把它实现为**对执行代价的乘性调制**——认知负担不产生动作，它让已有的动作更难做准：

$$c_i = c_i^{\text{phys}} \cdot (1 + \alpha\, C_i)$$

第一版只纳入一个认知量，**节奏不可预测度** $C$：取按下步的间隔序列，把当前间隔与此前 1–4 个间隔逐一比较，取最小的对数偏差 $\min_{\ell \le 4} |\log_2(\Delta_k / \Delta_{k-\ell})|$（小于 0.1 记 0，上限 1.5），再做半衰期 4 步的指数平滑。

- 周期不超过 4 的节奏型（等距、附点、摇摆、gallop、长短交替）读 0——可预测就不算难读；
- 拍点切换、变速、不成周期的混拍读正值；
- 它不读 BPM，不读拍线，记谱无关；
- 它只读**按下**的节奏。尾点时刻的参差是释放技法自己的事，由 $\tilde n$ 承担——原型曾把尾点并进同一条序列，结果 LN Release 池被「LN 技」拿走 10/15。

原型实测，它在谱面均值上把 Regular Tech 与另外三个米池分开：对 Speed AUC 0.964、对 Stream 0.902、对 Jack 0.813。它对 LN Tech 的分辨力弱（对另三个 LN 池 AUC 0.64–0.72），见 §10 Q6。

释放辨识项 $r_1 \tilde n$ 按 K8 的定性属于认知，但它以加性代价挂在释放动作上，因为它确实对应一个需要被做对的动作。

**没有纳入、且不应未经检验就纳入的**：排列层面的可预测度（轨位转移熵一类）与读谱密度。ADR-0015 已经量出 $\Omega_{\text{irreg}}$ 在 chordstream 上反而更高——随机多押天然「不可预测」。候选认知项的准入闸门见 §8 G5。

### 4.5 累积：负荷在生理结构上的堆积

代价注入两级效应器，各自指数衰减：

$$F_f(t) = \sum_{j:\, f_j = f,\ t_j \le t} c_j\, e^{-(t - t_j)/\tau_F}, \qquad H_h(t) = \sum_{j:\, f_j \in h,\ t_j \le t} c_j\, e^{-(t - t_j)/\tau_H}$$

$$\sigma_i = F_{f_i}(t_i) + \omega\, H_{h_i}(t_i)$$

- **指级** $F$ 承载同指的局部堆积：连叠的每一击都叠在上一击的余量上，稳态为 $c / (1 - e^{-w/\tau_F})$——K4 的饱和是累积的稳态，不需要 `tanh`。
- **手级** $H$ 承载整只手的负荷，它就是「密度」在本模型里的身份。ADR-0015 阶段② 的结论「段位阶梯就是密度阶梯、形状项需要水平载体」在这里不需要外挂 `peak_4m_nps`：载体是累积本身。粗搜给出的 $\tau_H$ 落在 2.5–5 s：手级负荷是几秒尺度上的积分。
- 同一步内的动作读到的是这一步全部注入之后的值。
- 累积是**线性**的：把每个动作的代价先按 §5 的归属表拆成 8 份再累积，得到的 8 份应变之和恰等于整体累积的应变，$\sigma_i = \sum_k \sigma_{i,k}$。记账穿过累积后守恒，§5 的恒等式全靠这一条。

**耐力**（几十秒量级的第三级累积）第一版不设，理由是实测：#56 的标本谱在只有两级累积的原型里读 7.90★（§9.5），长程效应由 §4.6 汇聚的亚线性长度项承担。见 §10 Q5。

### 4.6 汇聚：失误预算

设理想玩家能力为 $s$，做错应变为 $\sigma$ 的动作的概率在高能力端按幂律衰减：$q(\sigma, s) \approx (\sigma / s)^p$。**难度**定义为「期望失误数等于预算 $M$」时的能力：

$$\sum_i \Big(\frac{\sigma_i}{T}\Big)^p = M \quad\Longrightarrow\quad T = \Big(\frac{1}{M} \sum_i \sigma_i^p\Big)^{1/p}$$

（$M$ 并入星尺的截距。）这一个算子同时给出现行引擎用几套机制拼出来的性质：

| 性质 | 来源 | 现行引擎的对应物 |
| :--- | :--- | :--- |
| 顶部主导：应变低 30% 的动作只贡献 $0.7^p$（$p = 8$ 时 6%） | 幂 $p$ | P90 / Top5% 分位池化 |
| 垃圾时间不稀释：加入容易的段落几乎不改变 $T$ | 求和而非平均 | 「废除 `/duration_s`」 |
| 长度亚线性敏感：时长翻倍 $T$ 乘 $2^{1/p}$（$p = 8$ 时 +9%） | 求和 | 无（#56 的病灶） |
| 精确可分解：$T^p$ 是动作上的可加测度 | 求和 | 无 |

汇聚发生在**动作**上而不是时间格上，所以没有切片边界，也没有窗口长度这个常数。

Jinjin 的通过线（Regular 96%、LN 95%）是这条定义的社区对应物——段位本来就是「在这个准确率下打下来」。本设计不把这两个数写进公式（那会把判定规则引入固有难度），只借它说明「失误预算」与权威基准的口径是同一种。

## 5. 技法

### 5.1 技法 = 排列子集 + 一张归属表

技法由排列谓词定义：**哪些动作属于它**。一张归属表规定每个动作的代价记到谁名下，它是全引擎唯一承载技法语义的地方——改技法定义就是改表里的一行，不动应变。

| 步骤 | 动作 | 记给 |
| :--- | :--- | :--- |
| ① | 任意按下：先切出 $u$ 份额（节奏语境不可预测） | **Tech**（米语境）／ **LN Tech**（LN 语境） |
| ② | 余下 $1 - u$：**叠键类**按下——同轨上一键是米键、在紧邻的上一步（$\Delta k = 1$）、间隔 ≤ 220 ms（K1） | **Jack** |
| ② | 余下 $1 - u$：**反相类**按下——同轨上一物件是长条，尾→头间隔 ≤ 1 个局部步距 | **LN Inverse** |
| ② | 余下 $1 - u$：其它 LN 语境按下 | **LN General** |
| ② | 余下 $1 - u$：其它米语境按下 | **Stream** × $\chi$ ＋ **Speed** × $(1 - \chi)$ |
| ③ | 释放的辨识项 $r_1 \tilde n$（K7） | **LN Release** |
| ③ | 释放的基础项 $r_0$：该释放之后同轨紧跟反相复按 | **LN Inverse**（K8：反相的抬手是运动协调，不是松放判断） |
| ③ | 释放的基础项 $r_0$：其余 | **LN General** |

其中：

- $u_i = \min(1, C_i / C_{\text{ref}})$：节奏越不可预测，这个按下越多地属于「技」。
- $\chi_i \in [0,1]$ 是**多押语境**：前后各 8 步里多押步的占比。Speed 与 Stream 的差别按 CONTEXT.md 的词条取「叠键（chord）密度」，不取速度——慢的单音流也属于 Speed 子集，只是应变低。
- **LN 语境** $q_i$：该按下是长条头，或此刻任一手指正被锁住。

**重叠照常存在**：一个不可预测语境里的叠键按下同时属于 Tech 与 Jack；一次「抬手时还持有异长长条、随后同轨立刻复按」的释放同时属于 LN Release 与 LN Inverse。表做的事是让重叠的动作**拆账**——每个动作记出去的合计恰等于它自己的代价。

**通用技法拿余量**：Stream / Speed 与 LN General 没有自己的专属谓词，它们拿到的是「不属于任何专项类」的那部分。这是消除嵌套偏置的关键一步，见 §5.3。

**与 ADR-0015 决策 3 的差别**：那条决策让米侧技法把长条头按米音符计数。本设计里长条头记给 LN 侧，纯 LN 谱的米侧技法因此精确为 0。一份难度只记一次账，是 §5.3 的前提。

### 5.2 技法难度、总难度与恒等式

把每个动作的代价按归属表拆成 8 份再累积（§4.5），得到 $\sigma_i = \sum_k \sigma_{i,k}$。记成员权重 $u_{i,k} = \sigma_{i,k} / \sigma_i$（对 $k$ 求和为 1），技法难度是**同一个汇聚算子在技法自己那份上的读数**：

$$D_k = \Big(\sum_i u_{i,k}\, \sigma_i^p\Big)^{1/p} = \Big(\sum_i \sigma_{i,k}\, \sigma_i^{p-1}\Big)^{1/p}$$

于是

$$\sum_k D_k^p = \sum_i \sigma_i^p = T^p$$

这条恒等式带来三件事：

1. **总难度是技法难度的 $p$-范数**，$T \ge \max_k D_k$。ADR-0016 因为 8 轴不可比而放弃的「多面手加成」在这里不是一个可调的旋钮，而是定义的推论。
2. **主导技法只有一种读法**：$\arg\max_k D_k$。配套输出**份额** $s_k = (D_k / T)^p$，$\sum_k s_k = 1$——「这张谱的难度有百分之多少来自这个技法」。
3. **技法难度对份额不敏感**：份额 10% 时 $D_k = 0.1^{1/p}\, T \approx 0.75\,T$（$p = 8$）。读法是「这张 8★ 的谱里，叠的部分大约是 7★ 的叠」。技法难度回答「这部分有多难」，份额回答「这部分占多少」，两个问题不混在一个数里。

注意 $\sigma_{i,k}$ 是谱内语境下的读数：一个叠键按下的应变里既有它自己那根手指的堆积，也有整只手此刻的负荷。「该谱对应子集的难度」因此是**在这张谱里**打这部分有多难，不是把这部分音符单拎成一张谱的难度。

### 5.3 你预判的缺陷：实测与解法

**缺陷的精确形态。** 若技法难度取「全权重重叠子集的汇聚」$D_k^{\cup} = (\sum_{i \in S_k} \sigma_i^p)^{1/p}$，那么任何对集合包含单调的汇聚（max、top-k、$p$-范数和）都满足 $S_a \subseteq S_b \Rightarrow D_a^{\cup} \le D_b^{\cup}$。而技法子集天然有嵌套：全部长条动作 ⊇ 反相动作、辨识性释放、不可预测的 LN 动作；全部流式音符 ⊇ 不可预测的流式音符。**通用技法因此在结构上恒赢，与标定无关。**

原型实测（同一组常数、同一个应变场，只换口径。全权重子集的谓词：Jack = 叠键类按下；Stream / Speed = 其余按下里多押语境 $\chi \ge 0.5$ / $< 0.5$ 的；Tech / LN Tech = 米 / LN 语境里 $C > 0.15$ 的动作；LN General = 全部释放、全部长条头、同手有锁时的按下；LN Inverse = 反相类按下；LN Release = 同手有异长共持的释放）：

| 池 | 全权重重叠子集：主导 = 本池 | 拆账：主导 = 本池 |
| :--- | ---: | ---: |
| Regular Jack | 6/15 | 12/15 |
| Regular Tech | 3/15 | 10/15 |
| Regular Speed | 12/15 | 13/15 |
| Regular Stream | 15/15 | 14/15 |
| LN General | 14/15 | 13/15 |
| LN Tech | 0/15 | 0/15 |
| LN Inverse | 0/15 | 10/15 |
| LN Release | 0/15 | 0/15 |
| **合计** | **50/120** | **72/120** |

全权重口径下，三条专项 LN 阶梯的 45 张谱有 43 张被 LN General 拿走，Regular Jack 的 15 张有 8 张被 Stream 拿走，Regular Tech 的 15 张有 12 张被 Stream / Speed 拿走——正是你预判的形态。6 组种子上，全权重口径的命中是 47–54/120，拆账口径是 70–76/120。

拆账没有修好的两行（LN Tech、LN Release）不是嵌套偏置，是这两个技法在原型里还没有可用的代价项，见 §10 Q6。

**采纳的解法：重叠照常允许，但记账必须是单位分解，且通用技法只拿余量。** 病根不在「重叠」，而在「同一份难度被两个技法各记了一次全额」。归属表让每个动作的代价不重不漏地分出去，于是：

- 通用技法（Stream / Speed、LN General）只拿到不属于任何专项类的那部分——嵌套带来的结构性优势消失；
- 大而容易的子集拿不到主导，因为质量按 $\sigma^p$ 加权——动作再多，应变不在顶部就没有质量；
- 小而致命的子集拿得到主导，因为它的每个动作都落在顶部。

子集的大小仍然起作用，但只以它应得的方式：通过 $n^{1/p}$ 的亚线性暴露量（20 个音符对 2000 个音符，同等应变下难度差 $100^{1/8} = 1.78$ 倍），而不是通过包含关系。

**被否的修法**

| 修法 | 为什么不行 |
| :--- | :--- |
| 改用对包含不单调的汇聚（均值、分位数），或事后按子集大小归一 | 偏置反转：三五个音符的极端小子集读数最高，且小样本噪声大 |
| 覆盖博弈的 Shapley 值（每个动作在声称它的技法间平分） | 嵌套对里超集仍然赢：超集在重叠处拿一半，在非重叠处拿全部 |
| **按代价的成因拆账**（指钟项归 Jack / Inverse，锁指增量归 LN General，…）——本方案的前一稿 | 技法的身份被绑在机制项的**大小**上，而大小是由难度水平的标定决定的。原型实测：加入 K5 的锚之后，粗搜为了把低速反键压到 5★ 以内而把长条后复按的指钟项压到接近 0，LN Inverse 在自己池里的主导命中随之变成 **0/15**；同一组常数换成按排列类拆账是 **12/15**。「这是什么技法」与「它有多难」必须解耦——前者看排列，后者看应变 |

$D_k^{\cup}$ 保留为诊断输出，不参与主导判定。

## 6. 星尺

### 6.1 一条映射

$$\bigstar(x) = a \ln x + b$$

$T$ 与 8 个 $D_k$ 共用同一对 $(a, b)$。跨技法可比（#55）因此不是待解的问题：8 个技法星级是同一个场、同一个算子、同一条映射的读数，同一张谱上谁高谁低就是字面意思。对数形态是韦伯–费希纳式的选择：应变的等比变化对应星级的等差变化；它同时自带顶部压缩。

### 6.2 「那条尺」的可操作定义

「与玩家群体对 SR 的那条尺对齐，但不是对现有 SR 系统的拟合」需要一个能写进 CI 的定义。本设计的取法：

- **尺** = 官方 SR 在（轨，段位）上的中位数，共 30 个数（2 条轨 × 15 级，每格 4 张标杆谱）。它是刻度，不是系统：中位数把官方算法在单一技法上的偏置对消掉了。
- **对齐** = 30 个中位数落到尺上。$(a, b)$ 直接读它们；结构常数经由残差间接配合（§7 说清楚了这条通道）。
- **不拟合** = 结构常数的损失里没有任何逐谱官方 SR；逐谱官方 SR 只作为诊断指标报告（MAE、ρ，分轨）。

**为什么是双轨尺而不是现行的单尺。** 现行 `CANONICAL_DAN_SR` 让 8 个池在同一段位共用一个星值（0th = 3.2 … Stellium = 10.5）。官方 SR 不支持这个假设：

| 段位 | 单尺 | Regular 四池中位 | LN 四池中位 | LN Inverse / LN Release |
| :--- | ---: | ---: | ---: | ---: |
| 0th | 3.2 | 3.62 | 2.30 | 1.95 / 1.63 |
| 3rd | 4.5 | 5.08 | 3.29 | 2.32 / 2.71 |
| 5th | 5.3 | 5.34 | 4.60 | 4.17 / 3.81 |
| 10th | 7.4 | 6.82 | 7.74 | 7.84 / 8.21 |
| Stellium | 10.5 | 9.46 | 11.56 | 11.33 / 11.82 |

两条轨在 6th 与 7th 之间交叉：LN 低段明显低于米低段，LN 高段明显高于米高段。而且**同一条轨内，同段位的四个池也不等价**：LN Inverse 与 LN Release 的 3rd–6th 比 LN General 低 1.0–2.6★。这与游戏知识一致（K5：低速反键物理上不难，Jinjin 把它排在那个段位是因为图-底反转的读法门槛；K7：纯靠释放不提密度有上限）。ADR-0002 确立的是双轨制与**池内**梯度，没有断言跨池同段位等价——那是 `CANONICAL_DAN_SR` 这个非公理决策带进来的。

所以本设计**不假设跨池同段位等价**，并放弃 ADR-0016 的「逐维落带 ±8%」验收线：它要求的那件事在数据上不成立，在游戏知识上也不该成立。

## 7. 标定纪律

常数分三类，各有各的证据来源，不得串用：

| 类别 | 常数 | 允许的证据 |
| :--- | :--- | :--- |
| **结构常数**（17 个） | $K_H, a_H, K_J, a_J, g, \eta, \lambda_s, \lambda_o, r_0, r_1, \kappa, \alpha, C_{\text{ref}}, \tau_F, \tau_H, \omega, p$ | ① 8 条本维阶梯的序（ADR-0002）；② 游戏知识不变量，含以星为单位的锚（K5）；③ 生理先验给出的取值区间；④ 本池主导命中，仅对游戏知识支持的池；⑤ 尺的 30 个中位数在最优 $(a, b)$ 之后的残差 |
| **刻度常数**（2 个） | $a, b$ | 30 个（轨，段位）官方 SR 中位数 |
| **约定常数** | 步内聚容差 8 ms、叠键判定 220 ms、反相窗口 1 个局部步距、语境窗口 ±8 步、平滑半衰期 4 步 | 游戏知识直接给出，或需实测证明对结果不敏感 |

**禁止的证据**：逐谱官方 SR 进入结构常数的损失；逐谱或逐池的修正项；任何「为了让某张谱读对」而加的规则。

**官方 SR 在哪里碰到结构常数，说清楚**：两参数映射不可能独自把两条轨、15 级的中位数都放到尺上，所以结构常数必须配合（⑤）；K5 的锚以星为单位，也经由 $(a, b)$ 间接依赖这 30 个数。也就是说，官方 SR 以**30 个中位数**的粒度影响结构常数，以 **0 个逐谱值**的粒度影响任何东西。这是「对齐尺」与「拟合系统」之间我能画出的最清楚的线；线该不该画在这里，见 §10 Q1。

残差的处置顺序也是纪律的一部分：一处倒挂或一处与官方 SR 的大偏差，先按 ADR-0005 的六步 SOP 审那张谱，结论只有三种——缺一个代价项（补项，并过 G5 的准入闸门）、现有项的形态错了（改形态，重过全部不变量）、选铺问题（记入已知边界，由你裁定）。不存在第四种「调个常数压下去」。

### 9.6 标定出来的常数：哪些稳，哪些不稳

| 常数 | 冻结值（损失最低的一组） | 6 组种子的范围 | 读法 |
| :--- | ---: | ---: | :--- |
| $a_J$（指钟指数） | 3.10 | 2.77–3.47 | 稳。同指复击的代价对间隔极敏感 |
| $a_H$（手钟指数） | 1.16 | 0.85–1.41 | 稳。手内换指的代价约与间隔成反比 |
| $\tau_F$ | 0.52 s | 0.26–0.58 s | 量级稳 |
| $\tau_H$ | 3.9 s | 2.5–4.8 s | 量级稳：手级负荷是几秒的积分 |
| $C_{\text{ref}}$ | 0.28 | 0.26–0.43 | 稳 |
| $r_0$（释放基础） | 0.97 | 0.79–0.97 | 稳。一次释放的代价接近一次按下的基础代价 |
| $\eta$（释放宽限） | 479 ms | 307–509 ms | **等于把长条后复按的指钟项关掉** |
| $\lambda_s$（同手锁指压缩） | 0.10 | 0.07–0.12 | **接近关掉**；$\lambda_o$ 为 0.15–0.41 |
| $r_1$（释放辨识） | 0.09 | 0.09–0.43 | **接近关掉** |
| $\alpha$（认知增益） | 0.11 | 0.07–0.20 | 小。认知在原型里主要通过 $u$ 决定归属，而不是抬高代价 |
| $p$ | 9.3 | 5.3–13.5 | **不稳** |
| $\omega$（手级权重） | 0.91 | 0.22–0.91 | **不稳** |

三件事：

1. **米侧的结构是稳的**。两个时钟指数、两个时间常数在 6 组种子上落在同一量级。
2. **LN 侧的专项项被粗搜关掉了**。$\eta$ 被推到几百毫秒、$\lambda_s$ 与 $r_1$ 被压到 0.1：在这组标定里，一张 LN 谱的难度就是「按下 + 释放」两类动作的密度过时钟。这足以让总星级对官方 SR 的 ρ 到 0.986，足以让 LN General 与 LN Inverse 的阶梯基本单调，但不足以给 LN Release 与 LN Tech 一个身份，也不足以通过 K5 的拉伸测试。我的判断是这三项的**形态**不对（它们在慢谱上不够快地归零，所以 K5 的锚只能把它们整体压掉），不是现象不存在。
3. **$p$ 与 $\omega$ 没有被辨识**。序与尺对它们不敏感，需要别的证据（例如不同长度的同密度谱对）来定。

## 10. 需要你裁定的事

每条附我的推荐。

**Q1. 尺的口径：双轨尺还是单尺？**
推荐双轨尺（§6.2）。单尺要求 8 个池同段位同星，官方 SR 与 K5 / K7 都不支持。代价是「LN 0th 的谱读 2★ 出头」要被接受为正确读数。

**Q2. 技法难度取拆账口径还是全权重子集口径？**
推荐拆账口径作为对外读数（§5.2），全权重口径 $D_k^{\cup}$ 作为诊断。两者在本维阶梯上的序接近（原型平均 τ 0.964 对 0.955），差别全在主导判定与恒等式。

**Q3. 残余倒挂的归属。**
§9.3 的每一对需要逐条裁定是模型缺陷还是选铺问题。你已经裁定过 Jack 0th / 1st（选铺：1st 主体是切中带叠——原型实测该谱只有 2.9% 的按下是叠键类，0th 是 22.8%）。其余各对我的初判写在 §9.3，未经你确认不作数。

**Q4. 拇指归属。**
原型让拇指以 1/2 权重计入两只手。实际握法里空格归一只手的拇指，那只手是四指手。可选：维持中性取法（镜像不变，推荐作为第一版）；或把拇指动态归给当下负荷较轻的手。后者更真实，但引入一个离散决策，需要先过 G5。

**Q5. 是否需要耐力级累积。**
推荐第一版不设（§4.5）。判据：#56 的标本与「首尾拼接」不变量已经落在合理位置；若后续出现长程谱系统性读低，再以 G5 的流程加第三级。

**Q6. LN Tech 与 LN Release 的语义。**
节奏不可预测度能把 Regular Tech 分出来，但分不开 LN Tech（AUC 0.64–0.72）；Jinjin 的 LN Tech 池在语料上更像「米 LN 混编 + 长度参差」。LN Release 的辨识项被粗搜压到接近 0，于是它在自己池里 0/15 主导、阶梯 τ 0.905（现行引擎 0.962）。两条阶梯的读数目前基本是「总应变乘一个小份额」，不是技法自己的信号。需要两样东西：你像 ADR-0015 为速、反键、释放做的那样给出 LN Tech 的社区定义，我把它写成归属表的一行；LN Release 的辨识项需要一个在慢谱上归零、在快谱上有分量的形态（与 Q8 是同一个问题的两面）。另需裁定 ADR-0015 的既有口径「LN Release 不要求本池主导」是否沿用。

**Q7. 星尺两端的形态。**
顶端：推荐先不加 9.5★ 以上的 `tanh` 软上限，对数映射已经压缩顶部（原型在 LN 顶段反而读低）。底端：对数映射没有地板，极稀疏的谱读到 0★ 以下。推荐把映射换成底端有界的同族形态（如 $a \ln(1 + x / x_0) + b$，多一个常数），而不是事后截断——截断会破坏底端的单调性。

**Q8. K5 的门槛按字面有多硬，以及 LN 专项项的形态。**
这是两件连在一起的事。原型在真实的 LN Inverse 阶梯上基本落在律的区间里，但合成拉伸测试按字面不过（§9.5）。要过，反键的代价必须在慢速下比现在快得多地归零，这要求锁指项换形态——候选是让锁指压缩只作用于「释放 → 复按」这一个耦合动作而不是所有按下，或让它带一个独立的、更陡的指数。在动手之前需要你先裁定：BPM\* 140、15 NPS 的全锁反键，按你的体感是 5★ 还是 7★？ADR-0006 修订 1 记着这两个门槛没有在 BPM\* 刻度上重新推导过。
