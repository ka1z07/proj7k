在线谱面库

不用安装任何东西，打开就能用。

官方星级和引擎星级并排

每个难度都同时显示 osu! 官方星级（黄）和 proj7k 星级（蓝），并标出对应段位。按「偏差」排序就能找出被官方高估或低估的图。

按技法找图

想练叠键、切、反键还是放手？按主技法筛选，或者在搜索框里写 engine>5 engine<6 这样的条件，精确到星级区间。

谱师风格

每位谱师写过哪些 7K 图、偏爱哪类技法、整体难度落在哪个段位，一页看完。

不止 Ranked

Ranked、Loved、Qualified 之外，Pending、WIP 和坟图里的 7K 图也都收录。

装在自己电脑上的工具

下载后双击 dashboard.cmd，所有工具都在同一个网页里，点按钮就行，不用记命令。配合 osu!lazer 使用。

实时雷达

选歌时就知道这张图难在哪

在 osu!lazer 里切换谱面，旁边的网页立刻显示星级、段位和八项技法雷达（叠键、技巧、速度、耐力切，以及四项长条技法），还有整首歌的难度时间线。

曲库同步

把游戏里的星级换成 proj7k 星级

一键把整个 lazer 曲库的星级改成 proj7k 星级，并打上段位和技法标签，在游戏里就能按标签找图。写入前自动备份，随时一键还原成官方星级。

降阶练习

打不过的图，降到你能练的难度

选一张图和目标段位或星级，生成一张保留原图手型和节奏、只是更简单的练习谱，点「导入 osu!」直接进游戏。

谱面生成

拿一首歌直接出一张 7K 谱

给一个音频文件和目标段位，自动测 BPM、生成米键谱，并把难度调到目标星级附近，打包成 .osz。

回放与画像

从回放里看出自己的水平和短板

导入 lazer 里的历史回放，得到你在八项技法上各自对应的段位、整体水平，以及左右手、各轨道的发力习惯。单局回放可以逐帧回看，失误和最难的段落一目了然。

练习推荐

针对卡住的地方出练习包

根据回放找出让你断连的那一段，切出来做成由易到难的三档练习谱；也会从你本地曲库里挑适合补短板的图。

三步开始

  1. 下载 从 GitHub 下载 proj7k（绿色 Code 按钮 → Download ZIP），解压到任意文件夹。
  2. 安装 Python 装好 Python 3.14，在文件夹里运行一次 pip install -r requirements.txt。
  3. 打开面板 双击 dashboard.cmd，浏览器会自动打开控制台。

每一步的详细说明见 使用说明。
