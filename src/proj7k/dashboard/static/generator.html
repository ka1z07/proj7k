从一首歌的音频生成 7K 谱（米键，可选长条与反键），按目标段位或星级自动调密度；输出 .osu 与 .osz，可一键导入 osu!。

歌曲

用这张谱的音频、标题与背景；默认也借用它的 timing（BPM 与 offset），节奏最准。

目标
Timing
分轨：把歌拆成鼓、贝斯、人声、其他，每段只跟一层写。第一次勾选会安装 Demucs 与 PyTorch（数 GB），每首歌第一次分轨在 CPU 上约 1–3 分钟，之后读缓存。
Mapperatorinator：一个听音频写谱的模型，节奏和键位一起写，不读分轨与按段技法。借用参考谱面的 timing 时直接读那张谱的 timing（更快也更准），否则自己测。先写得比目标略难，再删音符降到目标星级，不够时重写，最多几次。勾「快速」所有窗口一起写，约快一倍，行与长条略少。第一次勾选会安装它的 Python 3.10 环境与 PyTorch（数 GB）；有 NVIDIA 显卡时每首约 1–4 分钟。
同一设置换个种子就是另一种配键。
