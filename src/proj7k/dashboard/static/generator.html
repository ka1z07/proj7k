技法配比
每个技法池选「多」或「少」：跑完所有次数，留下技法最合配比的一张；降难时先删「少」的、最后删「多」的。只能挑与删，加不出模型本来不写的技法。重写段落也按这里的配比挑。
Mapperatorinator 是一个听音频写谱的模型，节奏和键位一起写。有 timing（借用或手动）时照它写，更快也更准；否则自己测。先写得比目标略难，再删音符降到目标星级，不够时重写，最多几次。勾「快速」分几路同时写，约快一倍，行与长条略少。第一次生成会安装它的 Python 3.10 环境与 PyTorch（数 GB）；有 NVIDIA 显卡时每首约 1–4 分钟。
同一设置换个种子就是另一张谱。
