降阶练习
把一张谱降到目标段位或星级，可以保留它的主技法，也可以只追难度；输出练习谱与 .osz，可一键导入 osu!。

输入

跟随 osu!lazer：在游戏里换一张谱，这里就跟着换，不用复制路径。
或把 .osu 文件拖到这里 / 点击选择
目标
降阶方式
技法范围（可选）
给想控制的技法拉一个星级范围，降阶会把每个技法各自降进自己的范围，同时总星级降到目标；不管的留空。只删不加：低于下限的技法补不上，结果里会写差多少。设了范围就不再要求保留主技法。
只追难度：不再要求练习谱保留原谱的主技法，只把星级降到目标附近；仍然只删不改，保住强拍与和弦骨架、左右手平衡，也不会删出超过一小节的新空白。
可以连续提交：每次提交按当时的设置排进下方队列，依次执行。加入收藏夹需要 osu!lazer 处于关闭状态；也可以稍后点结果里的「导入 osu!」。
