## 安裝

需要：**osu!lazer**（proj7k 讀的是 lazer 的資料庫和回放，stable 版不支援），Windows 10 / 11 或 macOS。所有東西都在你自己電腦上執行，不需要登入，也不會上傳任何東西。

### Windows

1. 開啟 **[最新版本](https://github.com/ka1z07/proj7k/releases/latest)**，在頁面最下面的 Assets 裡下載 **Source code (zip)**。
2. 解壓到一個你找得到、以後不會挪的地方，比如 `文件\proj7k`。
3. 雙擊資料夾裡的 **`install.cmd`**。

   > [!NOTE]
   > 如果彈出「Windows 已保護您的電腦」，點「其他資訊」→「仍要執行」。proj7k 沒有買程式碼簽名證書，所以 Windows 不認識它。

4. 等黑色視窗跑完（第一次大約 3–10 分鐘，看網速）。它會依次：
   - 沒有 Python 3.14 和 Node.js 的話，用 Windows 自帶的 winget 裝上（可能彈出一次管理員確認）；
   - 在 proj7k 資料夾裡建一個獨立的 Python 環境（`.venv`），裝好依賴，不影響你電腦上別的 Python；
   - 下載 proj7k 的視窗程式，在**開始選單和桌面**放一個 proj7k 快捷方式；
   - 最後直接開啟 proj7k。

以後從開始選單或桌面上的 **proj7k** 開啟就行。

> [!TIP]
> 裝到一半提示「裝好了 Python / Node.js 但這個視窗還找不到它」，關掉視窗再雙擊一次 `install.cmd` 即可，已經做完的步驟會跳過。

### macOS

1. 同樣在 **[最新版本](https://github.com/ka1z07/proj7k/releases/latest)** 下載 **Source code (zip)**，解壓到比如 `~/Documents/proj7k`。
2. 開啟「終端機」，輸入 `sh `（後面有空格），把解壓出來的資料夾裡的 `install.sh` 拖進終端機視窗，按 Return。
   - 沒有 Python 3.14 或 Node.js 時會用 [Homebrew](https://brew.sh) 安裝；沒有 Homebrew 的話先按它主頁上的那一行命令裝好。
   - proj7k 的視窗裝在 `~/Applications/proj7k.app`。
3. 以後雙擊資料夾裡的 **`proj7k.command`** 開啟。

### 更新與解除安裝

**更新**：下載新版本的 zip，解壓後**覆蓋**原來的資料夾，再執行一次 `install.cmd`（Mac 上 `install.sh`）。用 git 的話 `git pull` 後同樣再執行一次。你的畫像、回放分析和設定存在使用者目錄裡（`~/.proj7k`、`~/.cache/proj7k`），更新不會丟。

> [!TIP]
> 更新之後到「回放與畫像 → 匯入 lazer 回放」再匯入一次，舊的回放會按新版本重新計算。

**解除安裝**：刪掉 proj7k 資料夾、開始選單和桌面上的快捷方式，以及 `%LOCALAPPDATA%\proj7k`（Mac 上是 `~/Applications/proj7k.app`）。想連資料一起刪，再刪掉使用者目錄下的 `.proj7k` 和 `.cache\proj7k`。用過「曲庫同步」的話，解除安裝前先點「還原為官方星級」。

## 第一次開啟

1. **開啟 osu!lazer**（開著關著都行，proj7k 只讀它的資料庫，遊戲開著也能讀）。lazer 裝在預設位置時會自動找到；在遊戲設定裡挪過資料目錄也能找到。
2. 開啟 proj7k，首頁就是你的**玩家主頁**：遊玩次數、評級、星級進步曲線、各段位通關情況，全部來自 lazer 裡儲存的成績，不需要登入或 API。
3. 點主頁「下一步練什麼」裡的 **「去匯入回放」**（或側邊欄「回放與畫像 → 匯入 lazer 回放」），填你的玩家名，點「開始匯入」。讀完回放後，主頁才會顯示你的**整體水平**、**八項技法實力**和**最該補的短板**。
4. 左下角 **「English / 中文」** 切換介面語言（第一次跟隨系統語言）。

proj7k 的視窗沒有瀏覽器的標籤欄和位址列，右上角是自己畫的最小化、最大化、關閉按鈕，拖標題欄可以移動視窗。關掉視窗不會打斷正在跑的任務（降階、生成、匯入回放都在後臺繼續）。

## 玩家：主頁、遊玩記錄、曲庫

- **主頁**：大字顯示你現在的水平（段位和星級）；遊玩次數、時長、準確率等六項和近 30 天對比；「下一步練什麼」給出最弱的一項技法（一鍵出短板練習譜）、你水平附近還沒打好的譜、下一個段位曲庫裡有幾張、通關了幾張；下面是星級進步曲線（點一個點開啟那一局）、八項技法實力、各段位通關情況、近半年活躍度、最難的通關和最近遊玩。
- **遊玩記錄**：每一局的評級、準確率、分數、連擊、Mod、星級（開了 DT/HT 按變速後的星級算）。可以搜尋、按評級 / 段位 / Mod 篩選、按星級或準確率排序、每張譜只看最好一局。
- **曲庫**：本機全部 7K 譜的封面、星級、段位、主技法和你的最好成績；「適合我練的」列出和你畫像實力相近、還沒玩過的譜。

**點開一局**：判定分佈、MAX:300、這局在這張譜上排第幾；能「診斷這局」（回放檢視器 + 存進畫像）、「在 osu! 裡重看」、下載 `.osr`、「在崩盤點切練習包」、「降階練習這張譜」。

**點開一張譜**：引擎星級、八項技法、難度隨時間、你在這張譜上的每一局、試聽；能直接去降階、用這首歌生成新譜、診斷最近一局，或開啟線上 7K 譜面庫 / osu! 官網的頁面。

## 工具

### 實時雷達

在 osu!lazer 裡換一張 7K 譜面，頁面馬上跟著重新整理：

- **星級與段位**：這張圖的 proj7k 星級和對應的段位。
- **八項技法雷達**：米鍵四項（疊鍵 Jack、技巧 Tech、速度 Speed、耐力切 Stream）和長條四項（LN 綜合、LN 技巧、反鍵、放手）。哪一項最突出，這張圖就主要考什麼。
- **難度時間線**：整首歌每一段有多難、由哪項技法撐起來。最高的幾段就是最容易斷連的地方。

適合放在第二個螢幕上，一邊選歌一邊看。直播時在 OBS 里加一個瀏覽器源，地址填 `http://127.0.0.1:7770/?mode=overlay`，就是透明背景的疊加層。

### 回放與畫像

這一頁有四個標籤：

**匯入 lazer 回放**：第一次用時先來這裡。填你的玩家名，點「開始匯入」，會把 osu!lazer 裡你所有的 7K 回放讀進畫像檔案。重複匯入是安全的，不會重複計數；太短或明顯是重開的局會被過濾掉。

**回放診斷**：分析一局回放。預設取你在遊戲裡當前選中的那張圖上最近一次遊玩，也可以選任意一局或自己拖 `.osr` 和 `.osu` 進來。可以勾選：

- **生成回放檢視器**：下落式回放，判定線上方是譜面、下方是你實際的按鍵，失誤、漏按、多按、長條早放一眼能看出來。底部的難度時間線可以拖動，能在失誤和最難的段落之間跳轉。
- **存入畫像檔案庫**：把這一局計入你的玩家畫像。
- **在崩盤點切三階練習包**：自動找到你斷掉的那一段，切出來做成由易到難的三張練習譜（Recovery 在你當前水平、Push 是原圖片段、Bridge 在中間），打包成 `.osz`。
- **練習推薦**：從你本地曲庫裡挑圖，「短板突破」補弱項，「長板專精」繼續拉強項（不會推薦段位考試的圖）。

**玩家畫像**：你在八項技法上各自對應的段位，以及整體水平。可以只看最近 N 天，也可以看全歷史。

**發力習慣**：從所有回放裡統計你的按鍵習慣，例如每一列偏早還是偏晚、按住多久、和絃裡哪根手指先按、滾鍵還是齊按、長條怎麼鬆手，以及中間那一列你習慣用哪隻手。

### 降階練習

打不過的圖，降成一張同樣的歌、同樣風格、但更簡單的練習譜。

1. 在遊戲裡選中這張圖（或者選「指定譜面」，填檔案路徑、譜面 ID 或 osu! 譜面連結，或直接拖 `.osu` 進來）。
2. 選目標：**段位**（比如 3rd）或 **星級**（比如 4.5）。
3. 選降階方式：
   - **保留主技法**：原圖是疊鍵圖，練習譜也還是疊鍵圖，只是更簡單。預設用這個。
   - **只追難度**：不強求保留主技法，只要難度降到目標附近。「保留主技法」降不到你要的難度時，結果裡會提示你改用這個。
4. 點 **「開始降階」**。

練習譜只刪音符、不加音符，強拍和和絃的骨架、左右手的平衡都會保留。勾上「打包 .osz」會帶上原曲音訊和背景；在結果裡點 **「匯入 osu!」** 就進遊戲了，勾選匯入選項的話還會自動放進「7K Practice」收藏夾。

### 譜面生成

給一首歌，自動生成一張 7K 譜。

1. 選歌：用「遊戲當前譜面的歌」（會借用那張譜的 BPM 和 offset，節奏最準），或「指定音訊」（mp3 / ogg / wav / flac，可以直接拖進來）。
2. 選目標段位或星級。
3. Timing（節奏）：有參考譜面時預設借用；沒有就選「自動測」（由模型測）；測得不對時選「手動」自己填 BPM 和第一個強拍的時間。
4. 選長條多少：不出長條（米譜）、少量長條、米長混、長條為主、通篇長條。
5. 點 **「生成」**。生成後會自動微調，讓難度落在目標附近，並打包成 `.osz`，可以一鍵匯入遊戲。

音符由 [Mapperatorinator](https://github.com/OliBomby/Mapperatorinator)（OliBomby，MIT）落鍵：一個聽著音樂把節奏和鍵位一起寫的模型。proj7k 先讓它寫得比目標略難，用自己的星級給每一次打分，刪音符降到目標，留下最接近的一張；聽起來一樣的樂句會寫成一樣。同樣的設定換一個「種子」數字，就會得到另一張譜。生成的譜是獨立的新譜面，不會覆蓋原來那張。

結果下方的 **「段落」** 卡片把譜按每 8 小節切成段：選幾段點「重寫所選」，模型只重寫這幾段（可以給目標星級，出幾個候選取最好的）；滿意的段可以鎖定，之後不再改動；也可以把一段錨定到另一段，寫成一樣或鏡像，來源段改了它也跟著變。每一版都是單獨的 `.osz`，可以復原、重做。

**「技法配比」**：引擎的八個技法池（Jack、Tech、Speed、Stamina、LN 綜合、LN Tech、反鍵、LN 放鍵）各選「多」或「少」。會跑完所有次數，留下技法最合配比的一張；降難時先刪「少」的、最後刪「多」的；重寫段落也按同樣的配比挑。它只能挑與刪，加不出模型本來不寫的技法（模型自帶的風格標籤測過，推不動 7K 譜，見 ADR-0047）。

> [!NOTE]
> 第一次生成會下載安裝模型（Python 3.10、PyTorch 和權重，數 GB）到 `~/.cache/proj7k/mapperatorinator`。強烈建議有 NVIDIA 顯示卡：每首約 1–4 分鐘，CPU 或 Mac 會慢很多。

### 曲庫同步

把遊戲裡 7K 圖的星級換成 proj7k 星級，這樣在 osu!lazer 裡按星級排序、篩選時用的就是 proj7k 的難度。同時會給每張圖打上段位和主技法標籤，在遊戲裡搜標籤就能找到對應的圖。

1. 點 **「預演（不寫入）」** 看看會改多少張圖，這一步什麼都不會改。
2. 點 **「立即同步」**。osu!lazer 開著的話，預設會先幫你關掉，寫完再開啟。

- **寫入前會自動備份**。想換回官方星級，點 **「還原為官方星級」** 即可。
- 只改你電腦上的遊戲資料庫，不影響線上成績和排名。

## 線上譜面庫

開啟 <https://7k.kaiz.dev/>，點「進入譜面庫」。不用安裝。網站有繁體中文、简体中文和 English，右上角「简 / 繁 / EN」切換（第一次跟隨瀏覽器語言）。

- **兩個星級並排**：每個難度都顯示 osu! 官方星級（黃色）和 proj7k 星級（藍色），以及對應的段位。排序選「偏差」可以找到兩邊差得最多的圖。
- **按技法找圖**：用「主技能」按鈕篩出以疊鍵、切、反鍵、放手等為主的圖。
- **搜尋條件**：搜尋框裡除了歌名、譜師，還可以寫條件，例如 `engine>5 engine<6`（proj7k 星級在 5 到 6 之間）。點搜尋框旁邊的「搜尋語法」可以看全部寫法。
- **隨機**：排序選「隨機」，每次重新整理換一批圖。
- **譜師**：頂欄「譜師」頁可以看每位譜師寫過哪些 7K 圖、擅長什麼技法。
- 除了 Ranked、Loved、Qualified，Pending、WIP 和墳圖裡的 7K 圖也收錄了。譜面詳情頁可以一鍵跳到 osu! 官網下載，或用 osu!direct 直接開啟。

## 星級和段位怎麼看

proj7k 的星級按 Jinjin 7K 段位考試標定，一共 15 級：

`0th` → `1st` → … → `10th` → `Gamma` → `Azimuth` → `Zenith` → `Stellium`

- 星級越高越難；每個段位對應一段星級區間，proj7k 和譜面庫會同時顯示兩者。
- proj7k 星級和 osu! 官方星級不是一把尺子，同一張圖兩邊數字不同是正常的。
- 八項技法各自也有星級，代表「這張圖在這一項上有多難」；對整張圖難度貢獻最大的那一項就是它的主技法。

## 常見問題

**會不會被封號？**
不會。proj7k 只讀你的回放和譜面檔案；「曲庫同步」只改你本機遊戲資料庫裡顯示的星級，不碰成績，也不上傳任何東西。

**主頁一直是空的 / 提示「未找到 osu!lazer 資料庫」？**
先確認用的是 osu!lazer 而不是 stable。資料目錄挪到了特別的地方時，可以在 proj7k 資料夾裡執行 `dashboard.cmd --lazer-dir "資料目錄"`（裡面有 `client.realm` 的那個資料夾）。還不行請提 [Issue](https://github.com/ka1z07/proj7k/issues)。

**主頁能看，但沒有水平和八項技法？**
還沒匯入回放。見[第一次開啟](#第一次開啟)第 3 步。

**點快捷方式沒反應 / 視窗一閃就沒了？**
在 proj7k 資料夾裡再雙擊一次 `install.cmd`，它會補上缺的東西。還不行的話雙擊 `dashboard.cmd`，用瀏覽器開啟（地址 <http://127.0.0.1:7770/>），黑色視窗裡會顯示出錯資訊，把它貼到 Issue 裡。

**不想用 proj7k 的視窗，想在瀏覽器裡用？**
雙擊 `dashboard.cmd`，瀏覽器會自動開啟 <http://127.0.0.1:7770/>。用的時候不要關那個黑色視窗。

**埠 7770 被佔用？**
通常是之前開的 proj7k 還沒關。或者用 `dashboard.cmd --port 7771` 換一個埠。

**曲庫同步後想換回官方星級？**
「曲庫同步」頁點「還原為官方星級」。

## 命令列用法（進階）

每個功能也都能在命令列裡用，適合批次處理。在 proj7k 資料夾裡執行（Windows 上先執行 `set PYTHONPATH=src`，macOS / Linux 在命令前加 `PYTHONPATH=src`；用安裝指令碼建好的環境時，把 `python3` 換成 `.venv\Scripts\python`，Mac 上 `.venv/bin/python`）：

| 用途 | 命令 |
| :--- | :--- |
| 開啟桌面端 | `python3 -m proj7k.desktop` |
| 只開控制檯（瀏覽器） | `python3 -m proj7k.dashboard` |
| 看一張圖的星級和技法 | `python3 -m proj7k.difficulty "譜面.osu"` |
| 降階到段位 / 星級 | `python3 -m proj7k.downscaler -i "譜面.osu" -d 3rd -o ./out`（`-s 4.5` 指定星級） |
| 生成譜面 | `python3 -m proj7k.generator --audio 歌.mp3 --target-dan 2nd` |
| 同步曲庫星級 / 還原 | `python3 -m proj7k.sync` / `python3 -m proj7k.sync --revert` |
| 診斷回放並開啟檢視器 | `python3 -m proj7k.profiler -r "回放.osr" -b "譜面.osu" --view --open` |
| 匯入 lazer 回放 | `python3 -m proj7k.profiler --import-replays --player "玩家名"` |
| 檢視玩家畫像 | `python3 -m proj7k.profiler -p "玩家名" --horizon-days 30` |

每個命令加 `--help` 可以看全部選項。

開發相關的文件（難度模型、設計決策、測試）在 [`CONTEXT.md`](CONTEXT.md)、[`docs/adr/`](docs/adr/) 和 [`CLAUDE.md`](CLAUDE.md)。開發進度與日誌見 <https://kaiz.dev/projects/proj7k/>。
